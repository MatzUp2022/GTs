# Top Alliance & promotion d'alliance — Guide (Last Light)

## 1. Échelle des ratings

- Ratings d'alliance : **Temporary → Basic → Intermediate → Premium → Top.**
- On monte via les **missions de promotion et les étoiles**.

## 2. Règles de promotion

- Les missions de promotion inachevées se réinitialisent à **0h00 (heure serveur)**.
- **Toutes les missions faites = 1 étoile** ; à **3 étoiles**, le rating peut augmenter.
- Après une étoile, les nouvelles missions ne se débloquent que **le lendemain**.
- Une fois terminées, **tous les membres** peuvent réclamer les récompenses — après la promotion, elles **expirent** ; chaque personnage ne peut réclamer qu'**une seule** récompense de promotion.

## 3. Missions quotidiennes de Top Alliance (exemples)

| Mission | Récompense (entre autres) |
|---------|---------------------------|
| 200 dons de tech d'alliance (au total) | 5 000 or · 100 médailles |
| 30 messages dans le canal d'alliance | 3 000 fer · 3 000 pain · 100 médailles |
| 30 monstres de rally vaincus | accél. 5m · médailles |

- **Toutes les missions quotidiennes faites** → récompenses quotidiennes (dont 500 médailles, un objet de tâche, 5 coffres, 5 boîtes).
- **Attention :** si les récompenses quotidiennes ne sont **pas réclamées, récompenses et missions se réinitialisent** — les réclamer est obligatoire !

## 4. Checklist (quotidienne, chaque membre)

- [ ] Don de tech d'alliance fait (compte pour les 200)
- [ ] Message posté dans le canal d'alliance (compte pour les 30)
- [ ] Participation aux monstres de rally (compte pour les 30)
- [ ] Récompense quotidienne réclamée (sinon réinitialisation !)
