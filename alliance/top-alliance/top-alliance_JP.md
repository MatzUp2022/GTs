# Top Alliance と同盟昇格 — ガイド (Last Light)

## 1. 評価ランク

- 同盟の評価: **Temporary → Basic → Intermediate → Premium → Top.**
- **昇格ミッションと星**で上がっていく。

## 2. 昇格のルール

- 未達成の昇格ミッションは**サーバー時間 0:00** に更新される。
- **全ミッション達成 = 星1つ**。**星3つ**で評価を上げられる。
- 星を得たあと、新しいミッションが開くのは**翌日**。
- 達成後は**全メンバー**が報酬を受け取れる — 昇格後は**失効**する。1キャラクターが受け取れる昇格報酬は**1つだけ**。

## 3. Top Alliance のデイリーミッション（例）

| ミッション | 報酬（一部） |
|------------|--------------|
| 同盟テックへの寄付 200 回（合計） | ゴールド 5,000 · メダル 100 |
| 同盟チャットに 30 件投稿 | 鉄 3,000 · パン 3,000 · メダル 100 |
| ラリーモンスター 30 体撃破 | 5分加速 · メダル |

- **デイリーミッション全達成** → デイリー報酬（メダル500、任務アイテム、宝箱5、ボックス5 など）。
- **注意:** デイリー報酬を**受け取らないと、報酬もミッションもリセットされる** — 受け取りは必須。

## 4. チェックリスト（毎日、全員）

- [ ] 同盟テックへ寄付した（200 にカウント）
- [ ] 同盟チャットに投稿した（30 にカウント）
- [ ] ラリーのモンスター討伐に参加した（30 にカウント）
- [ ] デイリーミッション報酬を受け取った（さもないとリセット）
