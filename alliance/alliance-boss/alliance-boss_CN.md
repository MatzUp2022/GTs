# Alliance Boss — 指南 (Last Light)

## 1. 阶段与流程

| 阶段 | 内容 |
|------|------|
| 选择 | R4/R5 选定难度与开始时间 — 需要**至少 20 名成员** |
| 准备 | 全员捐献资源 → 贡献奖励 + 伤害加成；达成目标后仍可继续捐 |
| 战斗 | **30 分钟**；由 R4/R5 手动开启，否则在服务器重置前 30 分钟自动开始；祭坛消失并召唤 Demons |
| 结算 | 按联盟总伤害与个人伤害发放奖励 |

## 2. 基本规则

- Demons **只能用集结攻击** — 不能单独进攻。
- 由 **R4 及以上**发起的集结会获得**额外伤害加成** → 优先发起或加入这类集结。
- **开启 Join Offline**，让你的部队在你离线时也参战。
- **祭坛捐献：** 捐 1 次 = **联盟贡献 ×500**；祭坛加成在 Lv. 5（满级）为对 Alliance Boss **伤害 +25 %**。
- 联盟总伤害越高，解锁的**难度越高**（例如 Lv. 6，奖励预览更好）。

## 3. MVP 机制

- **个人伤害最高**的玩家会把联盟奖励放大 **×1–10**（取决于个人伤害）— 最高 **Reward ×10**。
- → 最强的玩家专注拉满伤害，其他人负责把集结填满。

## 5. 清单

- [ ] 已向祭坛捐献（贡献 ×500）
- [ ] 已开启 Join Offline
