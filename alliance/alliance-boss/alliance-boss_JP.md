# Alliance Boss — ガイド (Last Light)

## 1. フェーズと流れ

| フェーズ | 内容 |
|----------|------|
| 選択 | R4/R5 が難易度と開始時刻を決める — **最低20名**が必要 |
| 準備 | 全員が資源を寄付 → 貢献報酬とDMGボーナス。目標達成後も寄付は続けられる |
| 戦闘 | **30分間**。R4/R5 が手動開始、しなければサーバーリセットの30分前に自動開始。祭壇が消えて Demons が現れる |
| 清算 | 同盟の合計DMGと個人DMGに応じて報酬 |

## 2. 基本ルール

- Demons は**ラリーでしか攻撃できない** — 単独攻撃は不可。
- **R4以上**が開始したラリーには**追加のDMGボーナス**が付く → そのラリーを優先して立てる・参加する。
- **Join Offline を有効に**して、離席中も自部隊が戦うようにする。
- **祭壇への寄付:** 1回の寄付 = **同盟貢献 ×500**。祭壇ボーナスは Lv. 5（最大）で Alliance Boss への **DMG +25 %**。
- 同盟の合計DMGが高いほど**上の難易度**が開放される（例: Lv. 6 はより良い報酬プレビュー付き）。

## 3. MVP の仕組み

- **個人DMGが最も高い**プレイヤーが、同盟報酬を **×1〜10** 倍にする（個人DMGに応じる）— 最大 **Reward ×10**。
- → 最強のプレイヤーはダメージ最大化に集中し、他の全員はラリーを埋める。
