# 团队指南 — 谁适合干什么，以及先练谁 (Last Light)

*依据英雄数据库中的技能数据推导。标注 **[推测]** 的条目可从技能描述推出，但未在游戏内确认。*

## 1. 支配所有阵容的两条规则

**阵营克制**（编队界面的信息按钮）：每个阵营只对一个特定的进攻方有抗性。

| 防守方 | 受到伤害降低 20 % 的来源 |
|--------|--------------------------|
| **Guardian** | Berserker |
| **Berserker** | Ranger |
| **Ranger** | Guardian |

→ 反过来读：**别**用 Berserker 打 Guardian，**别**用 Guardian 打 Ranger，**别**用 Ranger 打 Berserker。PvP（竞技场、Region Duel）中进攻前先看对方图标。

**编队加成**（按阵营构成，作用于全部五名英雄）：

| 编队 | HP / ATK / DEF |
|------|----------------|
| 同阵营 3 名 | +5 % |
| 同阵营 3 名 + 另一阵营 2 名 | +10 % |
| 同阵营 4 名 | +15 % |
| **同阵营 5 名（纯阵营）** | **+20 %** |

→ **纯阵营是最强的编队。** 别的阵营里稍强一点的英雄，得先把这 10–20 % 补回来才行。而且 Faction Trial 和 Frenzied Boss 本来就按阵营分 — 那里的 +20 % 是白给的。

## 2. 四条规律

1. **多段技能是打 Boss 最强的爆发。** 「对随机敌人攻击 X 次」在只有一个目标时会全部落在同一身上。Ella 的 *Phantom Volley*：8 × 117 % = **936 %**，5★ 16 段时约 1,870 %。作为对比，全阵容中最高的单次数值是 Irena 的 *Bounty Kill*，476 %。**[推测]**
2. **对怪加成与稀有度是两条独立的轴。** 没有任何 S+ 英雄带对怪加成，12 名 S 英雄里有 9 名带。在 PvE 活动中，一个带 +20 % 对怪伤害的 S 英雄常常打得过不带的 S+。
3. **只有 Loki 能给全队上进攻增益**（*Frenzied Beat*：全体友方 ATK +11.5 %，星级再加暴击 +10 % 和 2 回合）。其余都是自身增益。
4. **Clara 是唯一能给怪上减益的：** *Vital Drain* 让怪物**在 2 回合内受到 +12 % 伤害** — 这对全队都有效。

## 3. 谁在哪里发光

| 活动 | 核心阵容 | 原因 |
|------|----------|------|
| **World Boss**（单人，1 个目标）— 能凑齐 5 名加成阵营 | **Guardian：** Ella · Clara · Irena · Loki · Noctina — **Ranger：** Jessica · Grace · Bella · Gracie · Admira — **Berserker：** Sagitta · Sonic · Scarlett · Valkyrie · Noelle | 当日 +50 % 与纯阵营 +20 % 相叠 — 胜过一支更强的混编队 |
| **World Boss** — 凑不齐 5 名加成阵营 | **Ella · Clara** · Bella · Scarlett · Sonic/Jessica | 纯输出：多段爆发 + 对怪减益。有意识地放弃 +20 % 编队加成 |
| **Frenzied Boss**（3 只阵营 Boss） | Guardian：Ella、Clara、Irena · Ranger：Jessica、Grace、Bella · Berserker：Sagitta、Sonic、Scarlett | 强制要求三支阵营队伍 |
| **Alliance Boss**（集结，30 分钟） | 同 World Boss | 单体目标 + 对怪加成 |
| **Storm Rescue**（波次） | **Jessica**（对全体 243 %）· **Admira**（AoE + 法术减益）· Eileen（整排） | 唯一真正值得上 AoE 的活动 |
| **Peak / 3V3 Arena**（PvP） | **Viper + Marcus** · **Loki** · Ella/Jessica · Grace | 前排保护 + 唯一的团队 ATK 增益；Grace 狙后排 |
| **Faction Trial** | 三支互相独立的阵营队伍 | **每个英雄只能进一个试炼** — Ranger 和 Berserker（各 7 人）是瓶颈 |
| **Radar 精英 / 打怪** | Clara · Cassidy · Eileen · Gracie · Noelle | 对怪伤害往上，受怪伤害往下 |

## 4. 组合

- **战车作为第二个放大器：** *Global Strike* 命中 2 个目标，并让其**受到的总伤害在 1 回合内提升 15 %（★1）→ 20 %（★3，战车 Lv. 70）→ 25 %（★5，Lv. 110）**。★4（Lv. 90）只加物理伤害 — 完整的 +25 % 需要 Lv. 110。它对一切生效，不限于怪物 — 是游戏里最强的团队放大器。要在 Ella 的齐射之前放。
- **打 Boss 的核心：** Clara + Ella — 减益持续 2 回合，正好是 Phantom Volley 的窗口。再加 Loki，两人都有 ATK +11.5 %。
- **竞技场前排：** Viper（物理 −26 %）+ Marcus（DEF +35 %）— 两者通过星级都会扩展到**全体**友方，因此是叠加而不是互相覆盖。
- **嘲讽掩护：** Valkyra 拉住 2–4 名敌人，**并且**把他们的 ATK 降 11.5 % — 后排（Ella、Grace、Sonic）能多活一阵。
- **反法术：** Admira（敌方法术伤害 −12 %，受到能量伤害 −28 %）用来对付能量型输出。
- **后排 Guardian 的小技巧：** Irena 的 *Absolute Order* 给**后排的 Guardian 英雄 +13 % 对怪伤害** — 队里有 Irena 时，就把 Ella 和 Clara 放后排。

## 5. 培养优先级

**先看基地等级。** 如果某个英雄显示「Base Level needs to be increased!」，再往里投英雄经验都是白费。瓶颈在基地，不在英雄。

| # | 重点 | 理由 |
|---|------|------|
| 1 | **Ella** | 对 Boss 输出最高；每星最高 +270 %，齐射段数还会增加 |
| 2 | **Clara** | 唯一对怪的团队减益 + 战利品 +52 % — 她自己就能把成本赚回来 |
| 3 | **Loki 升到 5★** | 星级效果解锁全体暴击 +10 % 和 2 回合 |
| 4 | **一名强力 Berserker**（Sonic 或 Sagitta） | 最薄的阵营；Faction Trial 和 Frenzied Boss 都逼你三个阵营都要有 |
| 5 | **所有 2★ 英雄升到 3★ 以上** | 2★ 时技能上限只有 Lv. 5 且觉醒被锁 — 这是最便宜的进步 |
| 6 | **A 级英雄只做填充** | 2 个战斗技能，觉醒 +5 %，星级最高 +100 % — 别往里砸勋章 |

**装备：** 武器 + 头盔承载对怪伤害，护甲 + 手套承载减伤（见锻造手册）。打 Boss 的英雄先把**武器和头盔**推到 Lv. 10/20/30 — 那就是对怪伤害 +17 %。

## 6. 清单

- [ ] 基地等级够支撑主力输出
- [ ] 队伍尽可能做成纯阵营（+20 %）
- [ ] Ella、Clara、Loki 优先培养
- [ ] 三个阵营都有强力核心
- [ ] 没有英雄停在 3★ 以下（技能上限！）
- [ ] 打 Boss 英雄的武器 + 头盔已到 Lv. 10/20/30
