# チームガイド — 誰を何に、そして何から育てるか (Last Light)

*ヒーローデータベースのスキルデータから導いたもの。**[推測]** と付いた項目はスキルテキストから導けるが、ゲーム内では未確認。*

## 1. あらゆる編成を支配する2つのルール

**陣営の相性**（編成画面の情報ボタン）: 各陣営はちょうど1つの攻撃側に対して硬い。

| 防御側 | 被ダメージが20 %減る相手 |
|--------|--------------------------|
| **Guardian** | Berserker |
| **Berserker** | Ranger |
| **Ranger** | Guardian |

→ 裏返せば: Guardian に Berserker を**当てない**、Ranger に Guardian を**当てない**、Berserker に Ranger を**当てない**。PvP（アリーナ、Region Duel）では攻撃前に相手のアイコンを確認する。

**編成ボーナス**（陣営構成による。5体全員に適用）:

| 編成 | HP / ATK / DEF |
|------|----------------|
| 同一3体 | +5 % |
| 同一3体 + 別陣営2体 | +10 % |
| 同一4体 | +15 % |
| **同一5体（単一陣営）** | **+20 %** |

→ **単一陣営が最強の編成。** 他陣営の少し強いヒーローは、まずこの 10〜20 % を上回らなければならない。しかも Faction Trial と Frenzied Boss はもともと陣営で分かれる — そこでは +20 % が無料で付く。

## 2. 4つの法則

1. **多段スキルはボス相手に最強のバースト。** 「ランダムな敵にX回攻撃」は、敵が1体しかいなければ全弾が同じ標的に当たる。Ella の *Phantom Volley*: 8 × 117 % = **936 %**、5★で16ヒットなら約1,870 %。比較として、手持ちで最大の単発値は Irena の *Bounty Kill* で476 %。**[推測]**
2. **モンスターボーナスはレアリティとは別の軸。** S+ヒーローには誰も持っておらず、Sヒーローは12体中9体が持つ。PvEイベントでは、モンスターダメージ +20 % を持つSヒーローが、それを持たないS+ヒーローを上回ることが多い。
3. **味方全体を攻撃面で強化できるのは Loki だけ**（*Frenzied Beat*: 味方全体 ATK +11.5 %、星でさらに クリティカル +10 % と2ターン化）。それ以外はすべて自己バフ。
4. **モンスターにデバフを入れられるのは Clara だけ:** *Vital Drain* はモンスターの**被ダメージを2ターン +12 %** にする — これはチーム全体に効く。

## 3. どこで誰が光るか

| イベント | 主軸の編成 | 理由 |
|----------|------------|------|
| **World Boss**（単独、標的1体）— バフ陣営を5体そろえられる場合 | **Guardian:** Ella · Clara · Irena · Loki · Noctina — **Ranger:** Jessica · Grace · Bella · Gracie · Admira — **Berserker:** Sagitta · Sonic · Scarlett · Valkyrie · Noelle | 日替わりの +50 % と単一陣営の +20 % が重なる — より強い混成編成にも勝る |
| **World Boss** — バフ陣営が5体そろわない場合 | **Ella · Clara** · Bella · Scarlett · Sonic/Jessica | 純粋な火力: 多段バースト + モンスターデバフ。編成ボーナス +20 % を意図的に捨てる |
| **Frenzied Boss**（陣営ボス3体） | Guardian: Ella, Clara, Irena · Ranger: Jessica, Grace, Bella · Berserker: Sagitta, Sonic, Scarlett | 3つの陣営編成が必須になる |
| **Alliance Boss**（ラリー、30分） | World Boss と同じ | 単体標的 + モンスターボーナス |
| **Storm Rescue**（ウェーブ） | **Jessica**（全体に243 %）· **Admira**（AoE + 魔法デバフ）· Eileen（列全体） | AoE が本当に見合う唯一のイベント |
| **Peak / 3V3 Arena**（PvP） | **Viper + Marcus** · **Loki** · Ella/Jessica · Grace | 前列の保護 + 唯一のチームATKバフ。Grace が後列を狙撃する |
| **Faction Trial** | 陣営ごとに3つの独立した編成 | **各ヒーローは1つのトライアルのみ** — Ranger と Berserker（各7体）がボトルネック |
| **Radar エリート / 狩り** | Clara · Cassidy · Eileen · Gracie · Noelle | モンスターへのダメージを上げ、モンスターからの被ダメージを下げる |

## 4. 組み合わせ

- **車両という第二の増幅装置:** *Global Strike* は2体を攻撃し、その**総被ダメージを1ターン 15 %（★1）→ 20 %（★3、車両 Lv. 70）→ 25 %（★5、Lv. 110）**引き上げる。★4（Lv. 90）が足すのは物理ダメージのみで、完全な +25 % には Lv. 110 が要る。モンスターに限らずすべてに効く — ゲーム内で最強のチーム増幅。Ella のヴォレーの前に撃つ。
- **ボス用の核:** Clara + Ella — デバフは2ターン続き、Phantom Volley の枠とちょうど一致する。Loki を足せば両者に ATK +11.5 %。
- **アリーナの前列:** Viper（物理 −26 %）+ Marcus（DEF +35 %）— どちらも星で**味方全体**に広がるため、打ち消し合わずに重なる。
- **タウントによる庇護:** Valkyra は2〜4体を引きつけ、**さらに** ATK を 11.5 % 下げる — 後列（Ella, Grace, Sonic）が長く生き残る。
- **対魔法:** Admira（敵の魔法DMG −12 %、被エネルギーDMG −28 %）をエネルギー型アタッカーにぶつける。
- **後列 Guardian の小技:** Irena の *Absolute Order* は**後列の Guardian ヒーローにモンスターダメージ +13 %** を与える — Irena を入れるときは Ella と Clara を後列に置く。

## 5. 育成の優先順位

**まず拠点レベル。** ヒーローに「Base Level needs to be increased!」と出ていたら、そこから先のヒーローEXPはすべて無駄になる。ボトルネックはヒーローではなく拠点。

| # | 対象 | 理由 |
|---|------|------|
| 1 | **Ella** | ボスへの出力が最大。星ごとに最大 +270 % に加え、ヴォレーのヒット数も増える |
| 2 | **Clara** | モンスターに効く唯一のチームデバフ + 戦利品 52 % 増 — 自分で元を取る |
| 3 | **Loki を5★へ** | 星効果で全員に クリティカル +10 %、さらに2ターン化 |
| 4 | **強い Berserker を1体**（Sonic か Sagitta） | 最も層が薄い陣営。Faction Trial と Frenzied Boss は3陣営すべてを要求する |
| 5 | **2★のヒーローをすべて3★以上へ** | 2★ではスキル上限が Lv. 5 で覚醒もロック — 最も安上がりな伸びしろ |
| 6 | **Aヒーローは穴埋めのみ** | 戦闘スキル2つ、覚醒 +5 %、星は最大 +100 % — メダルを注がない |

**装備:** 武器と兜がモンスターへのダメージを、鎧と手袋が被ダメージ軽減を担う（フォージの手引き参照）。ボス狩り要員はまず**武器と兜**を Lv. 10/20/30 へ — それでモンスターへのダメージ +17 %。
