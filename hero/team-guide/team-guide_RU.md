# Руководство по командам — кто для чего и что качать первым (Last Light)

*Выведено из данных о навыках в базе героев. Пункты с пометкой **[предположение]** следуют из текстов навыков, но в игре не подтверждены.*

## 1. Два правила, определяющие любое построение

**Контр фракций** (кнопка информации в окне построения): каждая фракция защищена ровно от одного атакующего.

| Защитник | получает на 20 % меньше урона от |
|----------|----------------------------------|
| **Guardian** | Berserker |
| **Berserker** | Ranger |
| **Ranger** | Guardian |

→ В обратную сторону: **не** посылайте Berserker на Guardian, **не** посылайте Guardian на Ranger, **не** посылайте Ranger на Berserker. В PvP (арены, Region Duel) смотрите значки противника до атаки.

**Бонус построения** (по фракциям, действует на всех пятерых):

| Построение | HP / ATK / DEF |
|------------|----------------|
| 3 одинаковых | +5 % |
| 3 одинаковых + 2 другой | +10 % |
| 4 одинаковых | +15 % |
| **5 одинаковых (монофракция)** | **+20 %** |

→ **Монофракция — сильнейшее построение.** Немного более сильный герой другой фракции должен сначала перекрыть эти 10–20 %. А Faction Trial и Frenzied Boss и без того делятся по фракциям — там +20 % достаются бесплатно.

## 2. Четыре закономерности

1. **Многоударные навыки — сильнейшие нюки по боссам.** «X атак по случайным врагам» бьют в одну цель, когда цель всего одна. *Phantom Volley* Эллы: 8 × 117 % = **936 %**, а на 5★ с 16 ударами — около 1 870 %. Для сравнения: наибольшее одиночное значение в составе — *Bounty Kill* Ирены с 476 %. **[предположение]**
2. **Бонусы против монстров — ось, отдельная от редкости.** Ни у одного героя S+ их нет, у 9 из 12 героев S — есть. В PvE-событиях герой S с +20 % урона по монстрам часто обходит героя S+ без такого бонуса.
3. **Только Loki усиливает всю команду в атаке** (*Frenzied Beat*: всем союзникам ATK +11,5 %, плюс крит +10 % и 2 хода через звёзды). Всё остальное — самобаффы.
4. **Clara — единственный дебаффер монстров:** *Vital Drain* заставляет монстра **получать +12 % урона в течение 2 ходов** — это работает на всю команду.

## 3. Кто где хорош

| Событие | Базовый состав | Почему |
|---------|----------------|--------|
| **World Boss** (в одиночку, 1 цель) — есть пятеро баффнутой фракции | **Guardian:** Ella · Clara · Irena · Loki · Noctina — **Ranger:** Jessica · Grace · Bella · Gracie · Admira — **Berserker:** Sagitta · Sonic · Scarlett · Valkyrie · Noelle | Дневные +50 % и монофракционные +20 % складываются — это сильнее более мощной смешанной команды |
| **World Boss** — баффнутой фракции не набирается пятеро | **Ella · Clara** · Bella · Scarlett · Sonic/Jessica | Чистый урон: многоударный бурст + дебафф на монстра. Осознанный отказ от бонуса построения +20 % |
| **Frenzied Boss** (3 фракционных босса) | Guardian: Ella, Clara, Irena · Ranger: Jessica, Grace, Bella · Berserker: Sagitta, Sonic, Scarlett | Вынуждает держать три фракционные команды |
| **Alliance Boss** (рейд, 30 мин) | как на World Boss | Одна цель + бонусы против монстров |
| **Storm Rescue** (волны) | **Jessica** (243 % по всем) · **Admira** (AoE + дебафф магии) · Eileen (целый ряд) | Единственное событие, где AoE действительно окупается |
| **Peak / 3V3 Arena** (PvP) | **Viper + Marcus** · **Loki** · Ella/Jessica · Grace | Прикрытие фронта + единственный командный бафф ATK; Grace выбивает задний ряд |
| **Faction Trial** | три отдельные фракционные команды | **Каждый герой только в одном испытании** — узкие места это Ranger и Berserker (по 7) |
| **Radar elite / охота** | Clara · Cassidy · Eileen · Gracie · Noelle | Урон по монстрам вверх, получаемый от монстров — вниз |

## 4. Связки

- **Машина как второй усилитель:** *Global Strike* бьёт по 2 целям и повышает их **общий получаемый урон на 15 % (★1) → 20 % (★3, машина ур. 70) → 25 % (★5, ур. 110)** на 1 ход. ★4 (ур. 90) добавляет только физический урон — полные +25 % требуют ур. 110. Работает на всё, не только на монстров, — сильнейший командный усилитель в игре. Применяйте до залпа Эллы.
- **Ядро против боссов:** Clara + Ella — дебафф держится 2 хода, ровно окно для Phantom Volley. Добавьте Loki ради +11,5 % ATK обоим.
- **Фронт арены:** Viper (−26 % физического) + Marcus (+35 % DEF) — оба через звёзды распространяются на **всех** союзников, так что складываются, а не перекрываются.
- **Прикрытие провокацией:** Valkyra стягивает 2–4 врагов **и** режет им ATK на 11,5 % — задний ряд (Ella, Grace, Sonic) живёт дольше.
- **Против магии:** Admira (−12 % магического урона врага, −28 % получаемого энергетического урона) против энергетических дамагеров.
- **Приём с Guardian в заднем ряду:** *Absolute Order* Ирены даёт **героям Guardian в заднем ряду +13 % урона по монстрам** — ставьте Эллу и Клару назад, когда Ирена в команде.

## 5. Приоритет развития

**Сначала уровень базы.** Если у героя написано «Base Level needs to be increased!», весь дальнейший опыт героя пропадает впустую. Узкое место — база, а не герой.

| № | Фокус | Причина |
|---|-------|---------|
| 1 | **Ella** | Наибольший урон по боссам; до +270 % за звезду плюс больше ударов залпа |
| 2 | **Clara** | Единственный командный дебафф против монстров + 52 % больше добычи — окупает себя |
| 3 | **Loki до 5★** | Звёздный эффект открывает крит +10 % для всех и 2 хода |
| 4 | **Один сильный Berserker** (Sonic или Sagitta) | Самая тонкая фракция; Faction Trial и Frenzied Boss требуют все три |
| 5 | **Каждого героя 2★ поднять до 3★+** | На 2★ потолок навыка ур. 5 и пробуждение закрыто — самый дешёвый прогресс |
| 6 | **Герои A — только как заполнение** | 2 боевых навыка, пробуждение +5 %, звёзды до +100 % — медали на них не тратить |

**Снаряжение:** оружие и шлем несут урон по монстрам, броня и перчатки — снижение урона (см. руководство по кузнице). У охотников на боссов сначала доведите **оружие и шлем** до ур. 10/20/30 — это +17 % урона по монстрам.
