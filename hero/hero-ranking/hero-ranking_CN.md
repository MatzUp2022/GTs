# 英雄排行 — 谁打得最疼，谁扛得最久 (Last Light)

## 1. 这些榜单怎么读

- **伤害 = 技能倍率 × 该英雄的 ATK。** 这里排的是已记录的倍率，不是最终伤害 — 弱英雄身上的 670 % 技能，打不过强英雄身上的 512 % 技能。
- **星级效果没有算进来。** 游戏把它们显示成一条阶梯（+30/70/120/185/270 %），却没有说明某一级是替换前一级还是叠加在上面。按基础值排序才诚实；每名英雄的阶梯见英雄数据库。
- **Hero 标签页对未获得的英雄同样显示 ATK · HP · DEF · Soldier Capacity。** 真正的数值排行要从那里来。目前只有一名英雄这样记录在案：Rosa 在 Lv. 150 / 5★ — ATK 44.0K · HP 388.0K · DEF 5.2K · 兵力433 · CP 788,715。
- **看减伤要看作用范围，不是看数字。** 全部伤害／仅物理／仅能量／仅怪物是四回事，而「仅怪物」在竞技场一文不值。

## 7. 这对养成顺序意味着什么

- **最大的单次数字属于一名辅助。** Clara 的 Vital Drain 打 670 %，但目标随机。最大的**可指定**一击是 Rosa 的 Killshot Lock，614 %，而且只有它会溅射到后排。
- **面对单个 Boss，随机目标技能就变成单体技能。** 这会把排行整个翻过来：在 World Boss 里，Rosa 每次释放的 1,188 %（★4 把攻击上限提到5次后是 1,980 %）和 Ella 的 936 % 全部落在同一个身体上 — 远在任何单次命中之上。
- **范围伤害只有在敌人成群时才划算：** Frenzied Boss、Storm Rescue 和竞技场靠 Jessica 与 Admira；面对单个 Boss，她们的全体技能不过是一次小的单击。
- **暴击会乘上它上面的一切。** Rosa（+30 %）与 Jessica（+26 %）是暴击核心；星级放在她们身上，比放在只有平坦 ATK 被动的英雄身上更值。
- **两份榜单，两种用途。** 减伤与对怪伤害是 World Boss、集结和雷达的那一套，单次命中与暴击是竞技场的那一套 — 和英雄数据库里 S 与 S+ 的分工一致。

## 8. 检查清单

- [ ] 在相信倍率排行之前，已在 Hero 标签页读过自己的 ATK 数值
- [ ] Boss 战 → 上多段英雄（Rosa、Ella、Sagitta），不上单体爆发
- [ ] 敌人成群 → 上范围（Jessica、Admira、Eileen）
- [ ] 竞技场防守 → 算得上减伤的只有 Admira、Viper、Marcus、Valkyra
- [ ] 怪物类活动 → 上带对怪加成的英雄，而不是 S+ 的竞技场那一套
- [ ] 星级先给暴击核心，再给平坦的 ATK 被动
