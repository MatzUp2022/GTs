# Рейтинг героев — кто бьёт сильнее всех, кто держится дольше всех (Last Light)

## 1. Как читать эти списки

- **Урон = множитель навыка × ATK героя.** Здесь ранжированы задокументированные множители, а не итоговый урон: навык на 670 % у слабого героя проигрывает навыку на 512 % у сильного.
- **Звёздные эффекты не суммированы.** Игра показывает их лестницей (+30/70/120/185/270 %), не сообщая, заменяет ли ступень предыдущую или прибавляется к ней. Сортировка по базовым значениям делает порядок честным; лестница по каждому герою есть в базе героев.
- **Вкладка Hero показывает ATK · HP · DEF · вместимость солдат даже для героев, которых нет в наличии.** Отсюда и берётся настоящий рейтинг по характеристикам. Пока так задокументирован ровно один герой: Rosa на Lv. 150 / 5★ — ATK 44,0K · HP 388,0K · DEF 5,2K · 433 солдата · CP 788 715.
- **В снижении урона важна область действия, а не цифра.** Весь урон / только физический / только энергетический / только монстры — это четыре разные вещи, и «только монстры» на арене не стоит ничего.

## 7. Что это значит для порядка прокачки

- **Самая большая одиночная цифра принадлежит саппорту.** Vital Drain у Clara бьёт на 670 %, но цель выбирается случайно. Самый большой **наводимый** удар — Killshot Lock у Rosa на 614 %, и только он брызгает по заднему ряду.
- **Против одного босса навыки по случайной цели становятся одноцелевыми.** Это переворачивает рейтинг: на World Boss 1 188 % за применение у Rosa (1 980 %, как только ★4 поднимает лимит атак до 5) и 936 % у Ella ложатся в одно и то же тело — далеко впереди любого одиночного удара.
- **Площадь окупается только при нескольких врагах:** Jessica и Admira для Frenzied Boss, Storm Rescue и арен; против одного босса их навыки по всем врагам — всего лишь небольшой одиночный удар.
- **Крит умножает всё, что выше.** Rosa (+30 %) и Jessica (+26 %) — критическое ядро; звёзды на них стоят больше, чем звёзды на герое с плоской пассивкой на ATK.
- **Два списка — два назначения.** Снижение урона и урон по монстрам — это набор для World Boss, рейдов и радара, одиночный удар и крит — набор для арены: то же разделение, что S против S+ в базе героев.

## 8. Чек-лист

- [ ] Собственные значения ATK считаны во вкладке Hero, прежде чем доверять рейтингу множителей
- [ ] Бой с боссом → выставлен герой с серией ударов (Rosa, Ella, Sagitta), а не одноцелевой нюкер
- [ ] Несколько врагов → выставлена площадь (Jessica, Admira, Eileen)
- [ ] Оборона на арене → как снижение урона считаются только Admira, Viper, Marcus, Valkyra
- [ ] События с монстрами → выставлены герои с бонусом против монстров, а не наборы арены S+
- [ ] Звёзды сначала в крит-кэрри, затем в плоские пассивки на ATK
