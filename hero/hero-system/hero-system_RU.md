# Система героев — Руководство (Last Light)

## 1. Основные правила

- **Редкость** по цвету карточки: золото (до S+) > фиолетовый > синий; ранг в левом верхнем углу (например, **S+**).
- **Три фракции** с фильтрами: Guardian (башня) · Ranger (крылья) · Berserker (когти) — основа для Faction Trial и Frenzied Boss.
- **Значки ролей** перед уровнем: корона — урон · щит — защита · капля — поддержка.
- **Потолок уровня зависит от уровня базы** («Base Level needs to be increased!») — прокачка героев требует параллельного развития базы.

## 2. Построение: контр-механика и бонус состава

**Контр фракций** — каждая фракция получает **на 20 % меньше урона** ровно от одного атакующего:
Guardian ← Berserker · Berserker ← Ranger · Ranger ← Guardian.
То есть не бейте Guardian Берсерками, Ranger — Гардианами, а Berserker — Рейнджерами.

**Бонус построения** по фракциям, для всех пяти героев: 3 одинаковых **+5 %** · 3 + 2 другой **+10 %** · 4 одинаковых **+15 %** · 5 одинаковых **+20 %** HP/ATK/DEF.
→ **Монофракция лучше смешанных команд**, если только замена не заметно сильнее.

## 3. Звёзды и навыки

- **Повышение звёзд** даёт плоские характеристики (пример 5★: +43 067 HP · +5 234 ATK · +636 DEF) и открывает **звёздные эффекты навыков**.
- **4 навыка** у героя (пример Ella «Jungle Phantom», S+ Guardian, CP 2,06M):

| Навык | Тип | Эффект (пример) |
|-------|-----|-----------------|
| Forest Ambush | Активный (энергия) | 512 % ATK по одной цели; звёзды: +30/70/120/185/270 % сверху |
| Jungle Rage | Бафф | Энергетический урон +28 %; +3 % за звезду |
| Phantom Volley | Мульти (CS) | 8 атак по 117 % по случайным целям; звёзды поднимают до 12/16 атак + урон |
| Battle Will Awakening | Пробуждение (1/1) | HP, ATK и DEF +20 %, скорость +40 |

- Уровни навыков (до 30) стоят **медалей** (например, 10 000–21 500 за шаг) — вкладывайте их в основных дамагеров.

## 4. Снаряжение (4 слота: оружие · броня · шлем · перчатки)

- Легендарный набор «Doomsday»; **два пути улучшения**:
  - **Enhance (уровни):** каждые 10 уровней открывается дополнительная характеристика (например, шлем: ур. 10/30 ATK +250, ур. 20/40 универсальное снижение получаемого урона +2 %).
  - **Promote (звёзды):** усиливает дополнительные характеристики (например, оружие: за звезду ATK +750 или крит +5 %; броня: HP +31 500 или снижение физического урона +20 %).
- Примеры значений на ур. 40: оружие ATK +4 001 · крит +18,5 % · ATK +9,25 % (CP 157K); броня HP +47 032 · HP/DEF +7,5 % (CP 179K).
- **Quick Equip** автоматически надевает лучший доступный набор.

## 5. Приоритеты

- Планируйте состав **по фракциям** (по одной команде Guardian/Ranger/Berserker — см. руководство Faction Trial).
- Медали, звёзды и легендарное снаряжение идут в первую очередь **основным дамагерам** (корона) главных команд.
- Красные точки на карточках и слотах — невыполненные улучшения; разбирайте их регулярно.

## 6. Чек-лист

- [ ] Уровень базы достаточен для следующего уровня героя
- [ ] Медали навыков вложены в дамагеров
- [ ] Снаряжение улучшено (доп. характеристика каждые 10 уровней) и повышено в звёздах
- [ ] Три фракционные команды закрыты
- [ ] Красные точки в меню героев разобраны
