# ヒーローシステム — ガイド (Last Light)

## 1. 基本ルール

- **レアリティ**はカードの色で判別: 金（最高 S+）> 紫 > 青。評価は左上に表示（例: **S+**）。
- **3陣営**とフィルター: Guardian（塔）· Ranger（翼）· Berserker（爪）— Faction Trial と Frenzied Boss の土台。
- レベルの前に付く**役割アイコン**: 王冠 = アタッカー · 盾 = 防御 · しずく = サポート。
- **レベル上限は拠点レベルに縛られる**（「Base Level needs to be increased!」）— ヒーローの育成には拠点の並行進行が必要。

## 2. 編成: 相性と編成ボーナス

**陣営の相性** — 各陣営は特定の1陣営からの**被ダメージが20 %減る**:
Guardian ← Berserker · Berserker ← Ranger · Ranger ← Guardian。
つまり Guardian に Berserker を、Ranger に Guardian を、Berserker に Ranger をぶつけないこと。

**編成ボーナス**（5体の陣営構成による）: 同一3体 **+5 %** · 3 + 別陣営2 **+10 %** · 同一4体 **+15 %** · 同一5体 **+20 %** HP/ATK/DEF。
→ **単一陣営が混成編成に勝る**。代わりに入れるヒーローが明確に強い場合を除く。

## 3. 星とスキル

- **星を上げる**と固定ステータスが付き（例 5★: +43,067 HP · +5,234 ATK · +636 DEF）、**スキルの星効果**が開放される。
- ヒーローごとに**スキル4つ**（例: Ella「Jungle Phantom」、S+ Guardian、CP 2.06M）:

| スキル | 種別 | 効果（例） |
|--------|------|------------|
| Forest Ambush | アクティブ（エネルギー） | 単体に 512 % ATK。星: +30/70/120/185/270 % 追加 |
| Jungle Rage | バフ | エネルギーDMG +28 %。星ごとに +3 % |
| Phantom Volley | 多段（CS） | ランダム対象に 117 % の攻撃8回。星で 12/16 回 + DMG に上昇 |
| Battle Will Awakening | 覚醒（1/1） | HP・ATK・DEF +20 %、速度 +40 |

- スキルレベル（最大30）には**メダル**が要る（例: 1段階あたり 10,000〜21,500）— 主力アタッカーに集中させる。

## 4. 装備（4枠: 武器 · 鎧 · 兜 · 手袋）

- レジェンダリーの「Doomsday」セット。**強化ルートは2つ**:
  - **Enhance（レベル）:** 10レベルごとに追加ステータスが解放（例: 兜は Lv. 10/30 で ATK +250、Lv. 20/40 で被ダメージの汎用軽減 +2 %）。
  - **Promote（星）:** 追加ステータスを強化（例: 武器は星ごとに ATK +750 または クリティカル +5 %。鎧は HP +31,500 または 物理被ダメージ軽減 +20 %）。
- Lv. 40 での数値例: 武器 ATK +4,001 · クリティカル +18.5 % · ATK +9.25 %（CP 157K）。鎧 HP +47,032 · HP/DEF +7.5 %（CP 179K）。
- **Quick Equip** で利用可能な最良セットが自動装着される。

## 5. 優先度

- 手持ちは**陣営単位**で計画する（Guardian / Ranger / Berserker を各1編成 — Faction Trial の手引き参照）。
- メダル・星・レジェンダリー装備は、主力編成の**アタッカー**（王冠）から先に。
- カードや枠の赤い点は未処理の強化 — 定期的に消化する。
