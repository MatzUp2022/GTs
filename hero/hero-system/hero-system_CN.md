# 英雄系统 — 指南 (Last Light)

## 1. 基本规则

- **稀有度**看卡片颜色：金色（最高 S+）> 紫色 > 蓝色；评级显示在左上角（例如 **S+**）。
- **三个阵营**及筛选：Guardian（塔）· Ranger（翅膀）· Berserker（利爪）— 这是 Faction Trial 与 Frenzied Boss 的基础。
- 等级前的**定位图标**：皇冠 = 输出 · 盾牌 = 防御 · 水滴 = 辅助。
- **等级上限取决于你的基地等级**（「Base Level needs to be increased!」）— 英雄升级必须有基地同步推进。

## 2. 编队：克制与编队加成

**阵营克制** — 每个阵营受到特定一个阵营的**伤害降低 20 %**：
Guardian ← Berserker · Berserker ← Ranger · Ranger ← Guardian。
也就是说：别用 Berserker 打 Guardian，别用 Guardian 打 Ranger，别用 Ranger 打 Berserker。

**编队加成**按五名英雄的阵营构成：同阵营 3 名 **+5 %** · 3 + 另一阵营 2 名 **+10 %** · 同阵营 4 名 **+15 %** · 同阵营 5 名 **+20 %** HP/ATK/DEF。
→ **纯阵营优于混编**，除非替换进来的英雄明显更强。

## 3. 星级与技能

- **升星**提供固定属性（例如 5★：+43,067 HP · +5,234 ATK · +636 DEF），并解锁**技能的星级效果**。
- 每名英雄有 **4 个技能**（例：Ella「Jungle Phantom」，S+ Guardian，CP 2.06M）：

| 技能 | 类型 | 效果（示例） |
|------|------|--------------|
| Forest Ambush | 主动（能量） | 对单体 512 % ATK；星级：额外 +30/70/120/185/270 % |
| Jungle Rage | 增益 | 能量伤害 +28 %；每星 +3 % |
| Phantom Volley | 多段（CS） | 对随机目标进行 8 次 117 % 攻击；星级提升到 12/16 次 + 伤害 |
| Battle Will Awakening | 觉醒（1/1） | HP、ATK、DEF +20 %，速度 +40 |

- 技能等级（最高 30）需要**勋章**（例如每级 10,000–21,500）— 集中投给你的核心输出。

## 4. 装备（4 个槽位：武器 · 护甲 · 头盔 · 手套）

- 传说级「Doomsday」套装；**两条强化路线**：
  - **Enhance（等级）：** 每 10 级解锁一条额外属性（例如头盔：Lv. 10/30 ATK +250，Lv. 20/40 通用受到伤害减免 +2 %）。
  - **Promote（星级）：** 强化那些额外属性（例如武器：每星 ATK +750 或 暴击 +5 %；护甲：HP +31,500 或 物理受伤减免 +20 %）。
- Lv. 40 的数值示例：武器 ATK +4,001 · 暴击 +18.5 % · ATK +9.25 %（CP 157K）；护甲 HP +47,032 · HP/DEF +7.5 %（CP 179K）。
- **Quick Equip** 会自动穿上当前最好的一套。

## 5. 优先级

- 按**阵营**规划阵容（Guardian / Ranger / Berserker 各一队 — 见 Faction Trial 手册）。
- 勋章、星级和传说装备优先给主力队伍的**输出核心**（皇冠）。
- 卡片/槽位上的红点表示有待处理的强化 — 要定期清掉。
