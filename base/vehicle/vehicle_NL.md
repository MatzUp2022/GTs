# Vehicle (Armored Warmachine) — Gids (Last Light)

## 1. Basisregels

- Het voertuig **valt tijdens het gevecht doorlopend aan en kan zelf niet worden aangevallen**.
- De eigenschappen van het voertuig gaan met een **omrekenfactor** over op de **helden van het team** (bijv. elk 15 % voor ATK/HP/DEF) — het voertuig tilt het hele team op.
- **Skins (Appearance):** zowel uitgeruste als alleen bezeten styles geven passieve bonussen (bijv. +5 % DMG tegen monsters als uitgerust; bezit o.a. +8 % held-ATK, +5 % held-HP) — skins lonen ook ongebruikt.

## 2. Levelen & EXP-crit

- Levelen met **EXP-items**; een volle balk = levelstijging met betere eigenschappen.
- **EXP-crit:** zolang de balk **onder 80 %** staat is er **50 % kans op dubbele EXP**; vanaf 80 % geen crits, ook niet tijdens fasedoorbraken. → Voer EXP-items in stoten toe zolang je onder 80 % zit.
- **Skillniveaus stijgen automatisch** op voertuigniveau **30 / 50 / 70 / 90 / 110**.

## 3. Skill: Global Strike

- Basis: **426 % ATK** als fysieke schade op 2 vijanden.
- De stereffecten die de ontvangen schade van het doel verhogen gelden voor het **hele team** — dat maakt het voertuig de sterkste schadeversterker in de opstelling. Vuur het af vóór je carries hun burst doen.

| Ster | Effect |
|------|--------|
| ★1 | Doel krijgt +15 % DMG gedurende 1 beurt |
| ★2 | +20 % extra fysieke DMG |
| ★3 | Doel krijgt +20 % DMG gedurende 1 beurt |
| ★4 | +40 % extra fysieke DMG (voertuig Lv. 90) |
| ★5 | Doel krijgt +25 % DMG gedurende 1 beurt (Lv. 110) |

## 4. Modules (vanaf Base Lv. 15)

- **6 modules**, één per slot; een upgrade vereist **2× een module van hetzelfde niveau** (3 identieke modules smelten samen tot een betere kwaliteit; "Conversion Materials" zet restanten om).

| Module | Waarde (voorbeeld Lv. 6 → 7) |
|--------|------------------------------|
| CPU | Voertuig-HP 80.025 → 202.939 |
| Engine | Voertuig-ATK 3.811 → 9.664 |
| Tire | Voertuig-DEF 762 → 1.933 |
| Radar | Held-HP 42.195 → 92.244 |
| Armor | Held-DEF 401 → 878 |
| Turret | Held-ATK 2.009 → 4.392 · skill-DMG 2,5 → 3,5 % |

- Module-upgrades maken grote sprongen (tot ×2,5) — prioriteiten: **Turret** (held-ATK + skill-DMG) en **Radar** (held-HP).

## 5. Vooruitblik: Battle Advancement & Skill Core (vanaf serverdag 82)

- **Battle Advancement** versterkt het voertuig verder; bij **BA Lv. 10** gaat het **Skill Core-systeem** open.
- Per coreplan: **1 opening + 1 aanval + 1 verstoring + 1 verdedigingsskill**; kies het plan vóór het gevecht.
- Waardeer excellente/legendarische cores op door identieke cores te verbruiken; voer ongebruikte cores aan Battle Advancement; elke fasedoorbraak verhoogt de **skillversterking**.

- [ ] Gelevel richting de skilldrempels 30/50/70/90/110
- [ ] Turret- en Radar-modules voorrang gegeven; 3 identieke modules samengevoegd
- [ ] Skins verzameld (passieve bonussen ook ongebruikt)
- [ ] Vanaf dag 82: Battle Advancement voeden, coreplan vóór het gevecht ingesteld
