# Vehicle (Armored Warmachine) — Guide (Last Light)

## 1. Ground Rules

- The vehicle **attacks continuously during battle and cannot be attacked itself**.
- Vehicle attributes are converted to the **team's heroes** at a **conversion ratio** (e.g. 15 % each for ATK/HP/DEF) — the vehicle scales the whole team.
- **Skins (Appearance):** equipped and merely owned styles grant passive bonuses (e.g. +5 % DMG to monsters equipped; owned incl. +8 % hero ATK, +5 % hero HP) — skins pay off even unused.

## 2. Leveling & EXP Crit

- Level via **EXP items**; a full bar = level-up with better attributes.
- **EXP crit:** while the bar is **below 80 %** there is a **50 % chance of double EXP**; at 80 %+ no crits, nor during phase breakthroughs. → Feed EXP items in bursts while below 80 %.
- **Skill levels rise automatically** at vehicle levels **30 / 50 / 70 / 90 / 110**.

## 3. Skill: Global Strike

- Base: **426 % ATK** as physical damage to 2 enemies.
- The star effects that raise the target's damage taken apply for the **whole team** — that makes the vehicle the strongest damage amplifier in the line-up. Fire it before your carries burst.

| Star | Effect |
|------|--------|
| ★1 | Target takes +15 % DMG for 1 turn |
| ★2 | +20 % extra physical DMG |
| ★3 | Target takes +20 % DMG for 1 turn |
| ★4 | +40 % extra physical DMG (vehicle Lv. 90) |
| ★5 | Target takes +25 % DMG for 1 turn (Lv. 110) |

## 4. Modules (from Base Lv. 15)

- **6 modules**, one per slot; an upgrade needs **2× a module of the same level** (3 identical modules merge into a higher-quality one; "Conversion Materials" converts leftovers).

| Module | Value (example Lv. 6 → 7) |
|--------|---------------------------|
| CPU | Vehicle HP 80,025 → 202,939 |
| Engine | Vehicle ATK 3,811 → 9,664 |
| Tire | Vehicle DEF 762 → 1,933 |
| Radar | Hero HP 42,195 → 92,244 |
| Armor | Hero DEF 401 → 878 |
| Turret | Hero ATK 2,009 → 4,392 · skill DMG 2.5 → 3.5 % |

- Module upgrades jump hard (up to ×2.5) — priorities: **Turret** (hero ATK + skill DMG) and **Radar** (hero HP).

## 5. Outlook: Battle Advancement & Skill Core (from server day 82)

- **Battle Advancement** further enhances the vehicle; at **BA Lv. 10** the **Skill Core system** opens.
- Per core plan: **1 opening + 1 attack + 1 disruption + 1 defense skill**; pick the plan before battle.
- Star up excellent/legendary cores by consuming identical cores; feed unused cores into Battle Advancement; every phase breakthrough raises **skill amplification**.

- [ ] Turret and Radar modules prioritized; 3 identical modules merged
- [ ] Skins collected (passive bonuses even unused)
