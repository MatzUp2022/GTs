# Vehicle（Armored Warmachine）— 指南 (Last Light)

## 1. 基本规则

- 战车在战斗中**持续攻击，且自身不会被攻击**。
- 战车属性会按**转化率**加到**队伍英雄**身上（例如 ATK/HP/DEF 各 15 %）— 战车抬升的是整个队伍。
- **皮肤（Appearance）：** 已装备的和仅仅拥有的外观都会提供被动加成（例如装备时对怪物伤害 +5 %；拥有即含英雄 ATK +8 %、英雄 HP +5 %）— 不用也有收益。

## 2. 升级与 EXP 暴击

- 用 **EXP 道具**升级；进度条满即升级，属性变好。
- **EXP 暴击：** 进度条在 **80 % 以下**时有 **50 % 概率获得双倍 EXP**；到 80 % 以上不再暴击，阶段突破期间也不会。→ 趁 80 % 以下时集中投喂 EXP 道具。
- **技能等级会自动提升** — 在战车等级 **30 / 50 / 70 / 90 / 110** 时。

## 3. 技能：Global Strike

- 基础：对 2 名敌人造成 **426 % ATK** 的物理伤害。
- 提升目标受到伤害的星级效果作用于**整个队伍** — 这让战车成为阵容中最强的伤害放大器。要在你的输出爆发之前放。

| 星级 | 效果 |
|------|------|
| ★1 | 目标受到伤害 +15 %，持续 1 回合 |
| ★2 | 额外物理伤害 +20 % |
| ★3 | 目标受到伤害 +20 %，持续 1 回合 |
| ★4 | 额外物理伤害 +40 %（战车 Lv. 90） |
| ★5 | 目标受到伤害 +25 %，持续 1 回合（Lv. 110） |

## 4. 模块（基地 Lv. 15 起）

- **6 个模块**，每个槽位一个；升级需要**2 个同级模块**（3 个相同模块可合成更高品质；「Conversion Materials」用于转化多余部分）。

| 模块 | 数值（示例 Lv. 6 → 7） |
|------|------------------------|
| CPU | 战车 HP 80,025 → 202,939 |
| Engine | 战车 ATK 3,811 → 9,664 |
| Tire | 战车 DEF 762 → 1,933 |
| Radar | 英雄 HP 42,195 → 92,244 |
| Armor | 英雄 DEF 401 → 878 |
| Turret | 英雄 ATK 2,009 → 4,392 · 技能伤害 2.5 → 3.5 % |

- 模块升级跨度很大（最高 ×2.5）— 优先级：**Turret**（英雄 ATK + 技能伤害）和 **Radar**（英雄 HP）。

## 5. 展望：Battle Advancement 与 Skill Core（开服第 82 天起）

- **Battle Advancement** 进一步强化战车；到 **BA Lv. 10** 开启 **Skill Core 系统**。
- 每套核心方案：**开场 1 + 攻击 1 + 干扰 1 + 防御 1**；方案要在战斗前选好。
- 优秀/传说核心通过消耗相同核心升星；用不到的核心投入 Battle Advancement；每次阶段突破都会提升**技能增幅**。

## 6. 清单

- [ ] 趁进度条在 80 % 以下投喂 EXP 道具（暴击概率）
- [ ] 朝技能节点 30/50/70/90/110 推进等级
- [ ] 优先 Turret 和 Radar 模块；已合成 3 个相同模块
- [ ] 已收集皮肤（不使用也有被动加成）
- [ ] 第 82 天起：投喂 Battle Advancement，战前设好核心方案
