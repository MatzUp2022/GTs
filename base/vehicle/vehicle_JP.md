# Vehicle（Armored Warmachine）— ガイド (Last Light)

## 1. 基本ルール

- 車両は**戦闘中ずっと攻撃し続け、こちらが攻撃されることはない**。
- 車両のステータスは**変換率**で**部隊のヒーロー**に反映される（例: ATK/HP/DEF に各15 %）— 車両は編成全体を底上げする。
- **スキン（Appearance）:** 装着中のものだけでなく、所持しているだけのスタイルもパッシブボーナスを与える（例: 装着でモンスターへのDMG +5 %。所持分には ヒーローATK +8 %、ヒーローHP +5 % など）— 使わなくてもスキンは価値がある。

## 2. レベル上げと EXP クリティカル

- **EXPアイテム**でレベルを上げる。バーが満タンになるとレベルアップし、ステータスが向上する。
- **EXPクリティカル:** バーが **80 %未満**のあいだは **50 %の確率でEXPが2倍**。80 %以上ではクリティカルは起きず、フェーズ突破中も起きない。→ 80 %未満のうちにEXPアイテムをまとめて投入する。
- **スキルレベルは自動で上がる** — 車両レベル **30 / 50 / 70 / 90 / 110** で。

## 3. スキル: Global Strike

- 基礎: 敵2体に **426 % ATK** の物理ダメージ。
- 対象の被ダメージを上げる星効果は**編成全体**に作用する — これが車両を編成最強のダメージ増幅役にしている。アタッカーのバーストの前に撃つこと。

| 星 | 効果 |
|----|------|
| ★1 | 対象の被ダメージ +15 %（1ターン） |
| ★2 | 物理ダメージ +20 % 追加 |
| ★3 | 対象の被ダメージ +20 %（1ターン） |
| ★4 | 物理ダメージ +40 % 追加（車両 Lv. 90） |
| ★5 | 対象の被ダメージ +25 %（1ターン）（Lv. 110） |

## 4. モジュール（拠点 Lv. 15 から）

- **モジュールは6つ**、各スロットに1つ。強化には**同レベルのモジュールが2つ**必要（同一モジュール3つで上位品質に合成。「Conversion Materials」で余りを変換）。

| モジュール | 数値（例 Lv. 6 → 7） |
|------------|----------------------|
| CPU | 車両HP 80,025 → 202,939 |
| Engine | 車両ATK 3,811 → 9,664 |
| Tire | 車両DEF 762 → 1,933 |
| Radar | ヒーローHP 42,195 → 92,244 |
| Armor | ヒーローDEF 401 → 878 |
| Turret | ヒーローATK 2,009 → 4,392 · スキルDMG 2.5 → 3.5 % |

- モジュール強化は伸びが大きい（最大2.5倍）— 優先は **Turret**（ヒーローATK + スキルDMG）と **Radar**（ヒーローHP）。

## 5. 先の話: Battle Advancement と Skill Core（サーバー82日目から）

- **Battle Advancement** で車両をさらに強化でき、**BA Lv. 10** で **Skill Core システム**が開く。
- コアプランの構成: **開幕1 + 攻撃1 + 妨害1 + 防御1**。プランは戦闘前に選ぶ。
- 優秀/レジェンダリーのコアは同一コアを消費して星を上げる。使わないコアは Battle Advancement に回す。フェーズ突破のたびに**スキル増幅**が上がる。
