# Vehicle (Armored Warmachine) — Guide (Last Light)

## 1. Grundregeln

- Das Fahrzeug **greift im Kampf durchgehend an und kann selbst nicht angegriffen werden**.
- Fahrzeug-Werte werden zu einem **Umwandlungs-Verhältnis** (z. B. je 15 % ATK/HP/DEF) auf die **Helden des Teams** übertragen — das Fahrzeug skaliert also das ganze Team.
- **Skins (Appearance):** getragene und bloß besessene Styles geben passive Boni (z. B. +5 % DMG auf Monster getragen; besessen u. a. +8 % Hero ATK, +5 % Hero HP) — Skins lohnen auch ungenutzt.

## 2. Leveln & EXP-Crit

- Leveln über **EXP-Items**; volle Leiste = Level-Up mit besseren Werten.
- **EXP-Crit:** Liegt die Leiste **unter 80 %**, gibt es **50 % Chance auf doppelte EXP**; ab 80 % keine Crits, ebenso nicht bei Phasen-Durchbrüchen. → EXP-Items in Schüben unterhalb von 80 % füttern.
- **Skill-Level steigen automatisch** bei Fahrzeug-Level **30 / 50 / 70 / 90 / 110**.

## 3. Skill: Global Strike

- Basis: **426 % ATK** als physischer Schaden auf 2 Gegner.
- Die Sterneffekte mit „Ziel erleidet mehr DMG" wirken für das **ganze Team** — das Fahrzeug ist damit der stärkste Schadensverstärker der Aufstellung. Vor dem Burst der Carries zünden.

| Stern | Effekt |
|-------|--------|
| ★1 | Ziel erleidet +15 % DMG für 1 Runde |
| ★2 | +20 % extra physischer Schaden |
| ★3 | Ziel erleidet +20 % DMG für 1 Runde |
| ★4 | +40 % extra physischer Schaden (ab Fahrzeug Lv. 90) |
| ★5 | Ziel erleidet +25 % DMG für 1 Runde (ab Lv. 110) |

## 4. Module (ab Basis Lv. 15)

- **6 Module**, je eines pro Slot; Upgrade braucht **2× Modul gleicher Stufe** (3 gleiche Module lassen sich zu einem höherwertigen mergen; „Conversion Materials" wandelt Restbestände um).

| Modul | Wert (Beispiel Lv. 6 → 7) |
|-------|---------------------------|
| CPU | Vehicle HP 80.025 → 202.939 |
| Engine | Vehicle ATK 3.811 → 9.664 |
| Tire | Vehicle DEF 762 → 1.933 |
| Radar | Hero HP 42.195 → 92.244 |
| Armor | Hero DEF 401 → 878 |
| Turret | Hero ATK 2.009 → 4.392 · Skill-DMG 2,5 → 3,5 % |

- Modul-Upgrades springen stark (teils ×2,5) — Prioritäten: **Turret** (Hero ATK + Skill-DMG) und **Radar** (Hero HP).

## 5. Ausblick: Battle Advancement & Skill Core (ab Server-Tag 82)

- **Battle Advancement** verbessert das Fahrzeug weiter; ab **BA Lv. 10** öffnet das **Skill-Core-System**.
- Je Core-Plan: **1 Opening- + 1 Attack- + 1 Disruption- + 1 Defense-Skill**; Plan vor dem Kampf wählen.
- Excellent-/Legendary-Cores per gleichen Cores **sternen**; ungenutzte Cores in Battle Advancement verfüttern; jeder Phasen-Durchbruch erhöht die **Skill Amplification**.

## 6. Checkliste

- [ ] EXP-Items unterhalb von 80 % Leiste gefüttert (Crit-Chance)
- [ ] Auf Skill-Schwellen 30/50/70/90/110 hingelevelt
- [ ] Turret- und Radar-Modul priorisiert; 3 gleiche Module gemergt
- [ ] Skins eingesammelt (passive Boni auch unbenutzt)
- [ ] Ab Tag 82: Battle Advancement füttern, Core-Plan vor dem Kampf gesetzt
