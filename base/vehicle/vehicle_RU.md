# Vehicle (Armored Warmachine) — Руководство (Last Light)

## 1. Основные правила

- Машина **атакует непрерывно в течение боя, и её саму атаковать нельзя**.
- Характеристики машины переносятся на **героев отряда** по **коэффициенту конверсии** (например, по 15 % для ATK/HP/DEF) — машина усиливает всю команду.
- **Скины (Appearance):** и надетые, и просто имеющиеся стили дают пассивные бонусы (например, +5 % урона по монстрам в надетом виде; за владение — в том числе +8 % ATK героев, +5 % HP героев) — скины окупаются, даже если не надеты.

## 2. Прокачка и крит EXP

- Уровень растёт от **предметов EXP**; полная полоса = повышение уровня с лучшими характеристиками.
- **Крит EXP:** пока полоса **ниже 80 %**, есть **50 % шанс двойного EXP**; при 80 % и выше критов нет, как и во время прорывов фаз. → Вливайте EXP пачками, пока ниже 80 %.
- **Уровни навыка растут автоматически** на уровнях машины **30 / 50 / 70 / 90 / 110**.

## 3. Навык: Global Strike

- База: **426 % ATK** физическим уроном по 2 противникам.
- Звёздные эффекты, повышающие получаемый целью урон, действуют для **всей команды** — именно поэтому машина является сильнейшим усилителем урона в построении. Применяйте её до взрыва ваших дамагеров.

| Звезда | Эффект |
|--------|--------|
| ★1 | Цель получает +15 % урона на 1 ход |
| ★2 | +20 % дополнительного физического урона |
| ★3 | Цель получает +20 % урона на 1 ход |
| ★4 | +40 % дополнительного физического урона (машина ур. 90) |
| ★5 | Цель получает +25 % урона на 1 ход (ур. 110) |

## 4. Модули (с базы ур. 15)

- **6 модулей**, по одному на слот; для улучшения нужно **2 модуля того же уровня** (3 одинаковых модуля сливаются в модуль лучшего качества; «Conversion Materials» перерабатывает остатки).

| Модуль | Значение (пример ур. 6 → 7) |
|--------|-----------------------------|
| CPU | HP машины 80 025 → 202 939 |
| Engine | ATK машины 3 811 → 9 664 |
| Tire | DEF машины 762 → 1 933 |
| Radar | HP героев 42 195 → 92 244 |
| Armor | DEF героев 401 → 878 |
| Turret | ATK героев 2 009 → 4 392 · урон навыка 2,5 → 3,5 % |

- Улучшения модулей дают резкие скачки (до ×2,5) — приоритеты: **Turret** (ATK героев + урон навыка) и **Radar** (HP героев).

## 5. На перспективу: Battle Advancement и Skill Core (с 82-го дня сервера)

- **Battle Advancement** дополнительно усиливает машину; на **BA ур. 10** открывается система **Skill Core**.
- В плане ядер: **1 открывающий + 1 атакующий + 1 дезорганизующий + 1 защитный навык**; план выбирается до боя.
- Превосходные и легендарные ядра качаются звёздами за счёт одинаковых ядер; неиспользуемые ядра идут в Battle Advancement; каждый прорыв фазы повышает **усиление навыков**.

## 6. Чек-лист

- [ ] Предметы EXP влиты, пока полоса была ниже 80 % (шанс крита)
- [ ] Прокачка нацелена на пороги навыка 30/50/70/90/110
- [ ] Модули Turret и Radar в приоритете; 3 одинаковых модуля слиты
- [ ] Скины собраны (пассивные бонусы даже без надевания)
- [ ] С 82-го дня: кормить Battle Advancement, план ядер выставлен до боя
