# Research: Soldier — ガイド (Last Light)

## 1. ツリーの構成

- 繰り返される構成ブロック、各テック**5レベル**:
  **兵士ATK**（弾丸）+ **兵士DEF**（盾）→ **兵士HP**（ハート）→ **積載量**（リュック）— その後、同じテックがより高いコストで次の段階へ。
- 序盤のブロックは5レベル、後半は各テック**10レベル**。

## 2. 数値（段階8の例、各10レベル）

| テック | 効果 Lv. 1 → 10 | CP Lv. 1 → 10 |
|--------|-----------------|---------------|
| Offensive Training（兵士ATK） | +1.5 → 15 % | 4,645 → 74,042 |
| Defensive Training（兵士DEF） | +1.5 → 15 % | 4,645 → 74,042 |
| Premium Defense（兵士HP） | +1.5 → 15 % | 4,645 → 74,042 |

- 段階9も同じ伸び方（+1.5 → 15 %）でコストのみ上がる: CP **12,116 → 181,382**。

*Development ツリーから追加で: Training Speed Up 5（訓練速度 +1 → 10 %、CP 6,159 → 96,275）。*

## 3. 推奨順序

| 手順 | 内容 |
|------|------|
| 1 | まずブロックの ATK + DEF を上げる（戦闘力） |
| 2 | 次に HP（損耗が減る = 治療が減る） |
| 3 | 積載量は最後（1行軍あたりの収穫が増える。採集勢とトラック略奪に効く） |

## 4. 連動

- 完了は Arms Race の **「Research Tech」フェーズでテックCPあたり+1ポイント**として加算される。
- 兵士が強いことは **Region Duel**（Central City Clash: Lv. 8 の撃破がポイントになる）と、すべてのラリーイベントで直接効いてくる。
