# Research: Trade Truck — ガイド (Last Light)

## 1. ツリーの構成

- このツリーにはゲーム内で **「Economy Rec.」** の印が付いている。
- 構成ブロック（5または10レベル）: **資源ブースト**（パン/鉄/ゴールド）→ 2つの**護衛テック**（弾丸/盾付きの士官章、各10レベル）→ **トラック速度**（時計付きトラック）→ **積載 +1**（木箱 +1）+ **拳アイコンの木箱テック**（保護/略奪 — 効果はゲーム内で確認）→ **トラック +1**（1レベル）→ 鉱石トラックのマイルストーン（1レベル）。
- 数値表はスクリーンショットに含まれていなかった — ゲーム内のポップアップを確認。

## 2. 推奨順序

| 手順 | 内容 |
|------|------|
| 1 | まず資源ブーストとトラック速度（1往復あたりの取得量が増える） |
| 2 | 次に護衛テック（略奪への防御） |
| 3 | 積載 +1 と1レベルのマイルストーン（トラック +1）を開放 |

## 3. 連動

- **Region Duel（月〜金）:** 敵リージョンのトラックを略奪すると**リージョンポイント +100** — 自分のトラックも同様に狙われる。護衛とタイミングが守りになる。
- 完了は Arms Race の「Research Tech」フェーズに加算される（CPあたり+1ポイント）。

## 4. チェックリスト

- [ ] トラックの運行を定期的に開始（取得量はテックに比例）
- [ ] SvS週の前に護衛テックを上げた
- [ ] マイルストーン（トラック +1）を早めに開放
- [ ] 完了を Research Tech フェーズに合わせた
