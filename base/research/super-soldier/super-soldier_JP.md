# Research: Super Soldier — ガイド (Last Light)

## 1. ツリーの構成

- ここのテックは**10レベル**。ブロック構成: **HP / ATK / DEF Enhancement**（兵士1体あたりの固定値）→ **マイルストーン**（士官章、菱形の枠）→ 次のブロック。さらに**訓練速度**と**収容数**のテック（早送りまたはプラスのアイコンが付いた兵士）が加わる。
- **1レベルのマイルストーン**（0/1、光る兵士）が各ブロックの末尾にある — 例: **「Soldier 10」: ティア10兵士の訓練を開放**（37,154 CP。要 **Research Lab Lv. 30** + HP/ATK/DEF Enhancement 3 が Lv. 10。所要 ≈ 9日18時間）。
- **%テック**は強化ブロックの間に配置される: Premium Defense（兵士HP）、Offensive/Defensive Training（ATK/DEF）、士気、病院収容数、治療速度。
- **Super Soldier が 40 % 以上**（加えて Lab Lv. 21）で Siege/Defense Specializations が開く（Development の手引きを参照）。

## 3. 優先度と連動

- 固定値は**兵士1体ごとに**効く — 兵力に比例して伸びるので、大軍ほど得をする。
- ツリーの進捗はそのまま Specializations の**開放条件**（40 % 以上）でもある — 意識して進める。
- 完了は Arms Race の「Research Tech」フェーズに加算される（CPあたり+1ポイント）。
- **CP爆弾:** Enhancement 3 のレベルは最大 **253,512 CP** — Arms Race（Research Tech）と Alliance Duel（Research Incentive）にとって単発で最大の塊。
