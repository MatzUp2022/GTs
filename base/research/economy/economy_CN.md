# Research: Economy — 指南 (Last Light)

## 1. 科技树结构

- 循环出现的模块：**粮食与铁的生产**→ **黄金生产** → **粮食/铁采集**（镐）→ **黄金采集** → **里程碑建筑**（如农场、挖掘机）— 之后是同样的科技在更高费用下的下一阶。
- 每项科技有 **5 级**；里程碑只有 **1 级**，用于解锁下一模块（树中下一个里程碑锁定在 0/1）。
- 第三阶增加粮食、铁和黄金的**产量百分比科技**。

## 2. 推荐顺序

| 步骤 | 操作 |
|------|------|
| 1 | 先做生产科技 — 它们全天候被动生效 |
| 2 | 模块做满后立即研究里程碑（开启下一阶） |
| 3 | 如果你在地图上主动采集，接着做采集科技（镐） |
| 4 | 第三阶的产量百分比科技放最后 |

## 3. 与 Arms Race / SvS 的联动

- 完成会计入 Arms Race 的 **「Research Tech」阶段，每点科技 CP 得 1 分** — 经济研究要在该阶段完成。
- 产量提高会带动其他一切：联盟贡献（Alliance Tech）、建造和部队。

## 4. 清单

- [ ] 两个研究位都在运行（经济科技用作大型研究之间的填充）
- [ ] 及时研究里程碑（否则会卡住整个阶段）
- [ ] 完成时间安排在 Research Tech 阶段
