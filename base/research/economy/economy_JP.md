# Research: Economy — ガイド (Last Light)

## 1. ツリーの構成

- 繰り返されるブロック: **食料・鉄の生産** → **ゴールド生産** → **食料/鉄の採集**（つるはし）→ **ゴールド採集** → **マイルストーン建物**（農場、掘削機など）— その後、同じテックがより高いコストで次の段階へ。
- 各テックは**5レベル**。マイルストーンは**1レベル**で次のブロックを開放する（ツリー内の次のマイルストーンは 0/1 でロックされている）。
- 第3段階では食料・鉄・ゴールドの**産出量%テック**が加わる。

## 2. 推奨順序

| 手順 | 内容 |
|------|------|
| 1 | まず生産テック — 常時パッシブに効く |
| 2 | ブロックが埋まったらすぐマイルストーンを研究（次の段階が開く） |
| 3 | マップで能動的に採集するなら次に採集テック（つるはし） |
| 4 | 第3段階の産出量%テックは最後 |

## 3. Arms Race / SvS との連動

- 完了は Arms Race の **「Research Tech」フェーズでテックCPあたり+1ポイント**として加算される — 経済研究はそこで完了させる。
- 産出量が上がればすべてが伸びる: 同盟貢献（Alliance Tech）、建設、兵士。

## 4. チェックリスト

- [ ] 研究スロットが2つとも稼働中（経済は大型研究の合間の埋め合わせ）
- [ ] マイルストーンを早めに研究（放置すると段階全体が止まる）
- [ ] 完了を Research Tech フェーズに合わせた
