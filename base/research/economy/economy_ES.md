# Investigación: Economy — Guía (Last Light)

## 1. Estructura del árbol

- Bloques recurrentes: **producción de comida + hierro** → **producción de oro** → **recolección de comida/hierro** (pico) → **recolección de oro** → **edificio hito** (p. ej. granja, excavadora) — luego el siguiente nivel con las mismas tecnologías a costes mayores.
- Cada tecnología tiene **5 niveles**; los hitos tienen **1 nivel** y desbloquean el siguiente bloque (el siguiente hito del árbol está bloqueado en 0/1).
- El tercer nivel añade **tecnologías de rendimiento en %** para comida, hierro y oro.

## 2. Orden recomendado

| Paso | Acción |
|------|--------|
| 1 | Primero las tecnologías de producción — actúan pasivamente todo el día |
| 2 | Investigar el hito en cuanto el bloque esté completo (abre el siguiente nivel) |
| 3 | Seguir con las de recolección (pico) si se farmea activamente el mapa |
| 4 | Las tecnologías de rendimiento en % del tercer nivel al final |

## 3. Vínculo con el Arms Race / SvS

- Las finalizaciones cuentan en la fase **«Research Tech» del Arms Race con +1 punto por CP** — terminar ahí las investigaciones de economía.
- Más producción alimenta todo lo demás: contribuciones de alianza (Alliance Tech), construcción y tropas.

## 4. Lista de control

- [ ] Ambos huecos de investigación ocupados (economía como relleno entre investigaciones grandes)
- [ ] Hitos investigados pronto (si no, bloquean todo el nivel)
- [ ] Finalizaciones colocadas en la fase Research Tech
