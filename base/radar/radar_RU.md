# Radar — Руководство (Last Light)

## 1. Основные правила

- Радарные задания дают крупные награды, но у каждого есть **ограничение по времени** — успевайте их закрывать.
- **Обновление каждые 6 ч**; число новых заданий растёт с уровнем радара (например, ур. 8: 10 → ур. 9: 11), как и максимум активных заданий (8 → 9).
- Если при обновлении список полон, новые задания уходят в **хранилище** — оно ограничено (например, **35**), так что разбирайте запас вовремя.
- **Автозавершение:** 10 энергии за задание.

## 2. Уровни и бонусы

- Уровень растёт за выполненные задания (например, **1 000** для ур. 8 → 9); каждый уровень улучшает характеристики радара.
- **Бонус к золоту/железу/еде** растёт с уровнем (ур. 8: 10 % → ур. 9: 15 %).
- **С радара ур. 4:** [Help Allies] и [Supply Collection] можно завершать мгновенно, вместе с их серией наград.
- Каждое повышение уровня даёт бонусные задания (например, ур. 8+: Diamond Mine ×1 · Gold Mine ×1 · Supply Collection ×2 · Clear Zombies ×1). **Без альянса** на момент получения задания Help Allies не выдаются.

## 3. Типы заданий (шанс появления)

| Тип | Шанс | Редкость |
|-----|------|----------|
| Clear Zombies | 29,93 % | Common 8,98 · Superior 7,48 · Rare 5,99 · Epic 4,49 · Legendary 2,99 % |
| Help Allies | 29,93 % | как у Clear Zombies |
| Supply Collection | 19,95 % | только Legendary 0,2 % |
| Gather Resources | 19,95 % | Rare 9,98 · Epic 5,98 · Legendary 3,99 % |
| Excavation Mission | 0,24 % | только Legendary; с радара ур. 6 |

**Только 1 раз в день:** Eliminate Elite Zombie · Defeat Elite Zombie (по Rare 60 / Epic 30 / Legendary 10 %) · Kill a Zombie Overlord (Epic 80 / Legendary 20 %; нужен радар ур. 7 + база ур. 15) · Rescue a Resistance Force (60/30/10 %).

## 4. Стратегия SvS: копить до события

- Радар **важен для SvS** — подгоняйте завершения и награды под нужные фазы событий (Arms Race / Region Duel).
- **Заполните хранилище перед событием** (до 35 отложенных заданий): не трогайте задания и дайте 6-часовым обновлениям забить запас.
- **Закрывайте их пачкой во время события:** с автозавершением (10 энергии за задание) запас уходит быстро — заранее копите энергию.
- Следите за сроками: не копите так долго, чтобы задания сгорели.

## 5. Чек-лист

- [ ] Таймер обновления проверен (каждые 6 ч)
- [ ] Ежедневные задания (Elite / Overlord / Rescue) взяты
- [ ] Перед SvS/Arms Race: хранилище заполнено, энергия накоплена
- [ ] Во время события: отложенные задания закрыты пачкой
- [ ] Ни одно задание не потеряно по сроку
