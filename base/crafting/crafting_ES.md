# Fabricación de armas y equipo (Forja) — Guía (Last Light)

## 1. Reglas básicas

- Cuatro huecos, cada uno con su pestaña: **arma · armadura · casco · guantes**.
- Calidades: **gris < verde < azul < morado < naranja** — a mayor nivel, más CP y efectos extra.
- Un icono verde en una pestaña u objeto = **fabricable / mejora disponible**.
- Cada fabricación cuesta **materiales del color correspondiente + oro**; el resultado se equipa directamente al héroe.
- Los atributos extra bloqueados se desbloquean **mejorando a nv. 10 / 20 / 30** (ver el manual del sistema de héroes).

## 2. Las cuatro pestañas

| Pestaña | Función |
|---------|---------|
| **Craft Equipment** | Fabricar equipo (materiales + oro) |
| **Dismantle Equipment** | Desmontar equipo → materiales de vuelta |
| **Merge Material** | 4 materiales → 1 del **nivel superior** (flecha hacia arriba) |
| **Dismantle Materials** | 1 material → varios del **nivel inferior** (flecha hacia abajo) |

→ Los materiales fluyen **en ambos sentidos**: si falta morado, se fusiona azul; si falta azul, se rompe morado.

## 3. Ejemplo: el set Falcon (morado), cada pieza nv. 0/30

| Pieza | CP | Atributos básicos | Extra a nv. 10 / 20 / 30 |
|-------|----|-------------------|--------------------------|
| Falcon Assault Rifle (arma) | 5.238 | ATQ de héroes +192 · DEF +25 · **daño a monstruos +2,5 %** | +2 % de daño a monstruos cada uno |
| Falcon Helmet (casco) | 4.910 | ATQ +128 · PV +1.347 · **daño a monstruos +2,5 %** | +2 % de daño a monstruos cada uno |
| Falcon Armor (armadura) | 7.089 | PV +3.369 · DEF +12 · **daño de monstruos −2,5 %** | −2 % de daño recibido cada uno |
| Falcon Gloves (guantes) | 6.196 | PV +2.021 · DEF +25 · **daño de monstruos −2,5 %** | −2 % de daño recibido cada uno |

- **Nivel máximo 30**; los tres atributos extra se desbloquean a nv. 10, 20 y 30.
- Patrón: **arma + casco = ataque** (ATQ, daño a monstruos), **armadura + guantes = defensa** (PV, reducción de daño).
- Con todo al nv. 30 el set da **+17 % de daño a monstruos** y **−17 % de daño recibido de monstruos**.
- Coste de fabricación del ejemplo (arma): 150 cristales morados · 99.000 oro.

## 4. Secuencia recomendada

| Paso | Acción |
|------|--------|
| 1 | **Revisar el filtro de selección automática** (rueda dentada): ponerlo en «Azul o inferior» para no desmontar morado/naranja por error |
| 2 | Fundir el equipo viejo con Auto Select + Dismantle |
| 3 | Fusionar los materiales sobrantes de nivel bajo (Merge All) hasta cubrir la siguiente fabricación |
| 4 | Subir los cuatro huecos a la mejor calidad disponible y luego mejorarlos (nv. 10/20/30 para los atributos extra) |

## 5. Vínculos

- **VIP 5** da **+25 % de fabricación de equipo** (ver el manual VIP) — merece la pena guardar las fabricaciones grandes.
- Los bonos de daño contra monstruos actúan en el World Boss, el Frenzied Boss y las misiones de radar.
- *La información del evento no indicaba si fabricar puntúa en el Arms Race — comprobar en la pantalla del evento.*
