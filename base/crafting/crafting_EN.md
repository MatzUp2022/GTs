# Weapon & Equipment Crafting (Forge) — Guide (Last Light)

## 1. Ground Rules

- Four slots, each with its own tab: **weapon · armor · helmet · gloves**.
- Qualities: **grey < green < blue < purple < orange** — the higher the tier, the more CP and extra effects.
- A green icon on a tab or item means **craftable / upgrade available**.
- Every craft costs **materials of the matching colour + gold**; the result is equipped on your hero directly.
- Locked extra attributes unlock by **enhancing to Lv. 10 / 20 / 30** (see the hero system manual).

## 2. The Four Tabs

| Tab | Function |
|-----|----------|
| **Craft Equipment** | Craft equipment (materials + gold) |
| **Dismantle Equipment** | Break down equipment → materials back |
| **Merge Material** | 4 materials → 1 of the **next tier up** (arrow up) |
| **Dismantle Materials** | 1 material → several of the **tier below** (arrow down) |

→ Materials flow **both ways**: short on purple, merge up from blue; short on blue, break purple down.

## 3. Example: the Falcon set (purple), each Lv. 0/30

| Piece | CP | Basic attributes | Extra at Lv. 10 / 20 / 30 |
|-------|----|------------------|---------------------------|
| Falcon Assault Rifle (weapon) | 5,238 | Hero ATK +192 · DEF +25 · **DMG to monsters +2.5 %** | +2 % DMG to monsters each |
| Falcon Helmet (helmet) | 4,910 | Hero ATK +128 · HP +1,347 · **DMG to monsters +2.5 %** | +2 % DMG to monsters each |
| Falcon Armor (armor) | 7,089 | Hero HP +3,369 · DEF +12 · **monster DMG −2.5 %** | −2 % monster DMG taken each |
| Falcon Gloves (gloves) | 6,196 | Hero HP +2,021 · DEF +25 · **monster DMG −2.5 %** | −2 % monster DMG taken each |

- **Max level 30**; the three extra attributes unlock at Lv. 10, 20 and 30.
- Pattern: **weapon + helmet = offense** (ATK, monster damage), **armor + gloves = defense** (HP, damage reduction).
- Fully enhanced to Lv. 30 the set gives **+17 % DMG to monsters** and **−17 % monster DMG taken**.
- Example craft cost (weapon): 150 purple crystals · 99,000 gold.

## 4. Recommended Sequence

| Step | Action |
|------|--------|
| 1 | **Check the auto-select filter** (gear icon): set it to "Blue or lower" so no purple/orange gets scrapped by accident |
| 2 | Melt down old equipment via Auto Select + Dismantle |
| 3 | Merge surplus low-tier materials up (Merge All) until they cover the next craft |
| 4 | Bring all four slots to the best available quality, then enhance them (Lv. 10/20/30 for the extra attributes) |

## 5. Links

- **VIP 5** grants **+25 % equipment crafting** (see the VIP manual) — worth saving big crafts for.
- Monster DMG bonuses apply at World Boss, Frenzied Boss and radar missions.
- *Whether crafting scores in the Arms Race was not stated in the event info — check the event screen.*
