# 武器・装備の製作（Forge）— ガイド (Last Light)

## 1. 基本ルール

- 4つの枠、それぞれ専用のタブがある: **武器 · 鎧 · 兜 · 手袋**。
- 品質: **灰 < 緑 < 青 < 紫 < オレンジ** — 上位ほどCPも追加効果も多い。
- タブやアイテムに緑のアイコンが付いていれば**製作可能 / 強化可能**。
- 製作には**対応する色の素材 + ゴールド**が必要。できたものはそのままヒーローに装着される。
- ロックされた追加ステータスは **Lv. 10 / 20 / 30 への強化**で開放される（ヒーローシステムの手引き参照）。

## 2. 4つのタブ

| タブ | 機能 |
|------|------|
| **Craft Equipment** | 装備を製作（素材 + ゴールド） |
| **Dismantle Equipment** | 装備を分解 → 素材が戻る |
| **Merge Material** | 素材4つ → **1段階上**の素材1つ（上向き矢印） |
| **Dismantle Materials** | 素材1つ → **1段階下**の素材を複数（下向き矢印） |

→ 素材は**双方向に流せる**: 紫が足りなければ青から合成して上げ、青が足りなければ紫を分解して下げる。

## 3. 例: Falcon セット（紫）、各 Lv. 0/30

| 部位 | CP | 基本ステータス | Lv. 10 / 20 / 30 での追加 |
|------|----|----------------|---------------------------|
| Falcon Assault Rifle（武器） | 5,238 | ヒーローATK +192 · DEF +25 · **モンスターへのDMG +2.5 %** | 各回 モンスターへのDMG +2 % |
| Falcon Helmet（兜） | 4,910 | ヒーローATK +128 · HP +1,347 · **モンスターへのDMG +2.5 %** | 各回 モンスターへのDMG +2 % |
| Falcon Armor（鎧） | 7,089 | ヒーローHP +3,369 · DEF +12 · **モンスターからのDMG −2.5 %** | 各回 被モンスターDMG −2 % |
| Falcon Gloves（手袋） | 6,196 | ヒーローHP +2,021 · DEF +25 · **モンスターからのDMG −2.5 %** | 各回 被モンスターDMG −2 % |

- **最大レベルは30**。追加ステータス3つは Lv. 10、20、30 で開く。
- 法則: **武器 + 兜 = 攻撃**（ATK、対モンスターダメージ）、**鎧 + 手袋 = 防御**（HP、被ダメージ軽減）。
- Lv. 30 まで完全に強化すると、セットで**モンスターへのDMG +17 %**、**被モンスターDMG −17 %**。
- 製作コストの例（武器）: 紫クリスタル150 · ゴールド99,000。

## 4. 推奨手順

| 手順 | 内容 |
|------|------|
| 1 | **自動選択フィルタを確認**（歯車アイコン）: 「Blue or lower」にして、紫やオレンジを誤って分解しないようにする |
| 2 | Auto Select + Dismantle で古い装備を溶かす |
| 3 | 余った低位素材を上へ合成（Merge All）し、次の製作費をまかなえるまで進める |
| 4 | 4枠すべてを入手可能な最高品質にしてから強化する（追加ステータスのため Lv. 10/20/30） |

## 5. 連動

- **VIP 5** で**装備製作 +25 %**（VIP の手引き参照）— 大きな製作はここまで取っておく価値がある。
- 対モンスターのDMGボーナスは World Boss、Frenzied Boss、レーダー任務で効く。
- *製作が Arms Race で得点になるかはイベント情報に記載がない — イベント画面で確認のこと。*
