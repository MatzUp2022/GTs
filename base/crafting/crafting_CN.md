# 武器与装备打造（Forge）— 指南 (Last Light)

## 1. 基本规则

- 四个槽位，各有独立标签页：**武器 · 护甲 · 头盔 · 手套**。
- 品质：**灰 < 绿 < 蓝 < 紫 < 橙** — 品质越高，CP 和额外效果越多。
- 标签或物品上出现绿色图标表示**可打造 / 有可用强化**。
- 每次打造都要消耗**对应颜色的材料 + 黄金**；成品会直接装备到你的英雄身上。
- 锁定的额外属性通过**强化到 Lv. 10 / 20 / 30** 解锁（见英雄系统手册）。

## 2. 四个标签页

| 标签 | 功能 |
|------|------|
| **Craft Equipment** | 打造装备（材料 + 黄金） |
| **Dismantle Equipment** | 分解装备 → 返还材料 |
| **Merge Material** | 4 个材料 → 1 个**高一阶**的材料（向上箭头） |
| **Dismantle Materials** | 1 个材料 → 多个**低一阶**的材料（向下箭头） |

→ 材料可以**双向流动**：紫色不够就把蓝色合上去；蓝色不够就把紫色拆下来。

## 3. 示例：Falcon 套装（紫色），各件 Lv. 0/30

| 部件 | CP | 基础属性 | Lv. 10 / 20 / 30 的额外属性 |
|------|----|----------|------------------------------|
| Falcon Assault Rifle（武器） | 5,238 | 英雄 ATK +192 · DEF +25 · **对怪物伤害 +2.5 %** | 每档 对怪物伤害 +2 % |
| Falcon Helmet（头盔） | 4,910 | 英雄 ATK +128 · HP +1,347 · **对怪物伤害 +2.5 %** | 每档 对怪物伤害 +2 % |
| Falcon Armor（护甲） | 7,089 | 英雄 HP +3,369 · DEF +12 · **怪物伤害 −2.5 %** | 每档 受怪物伤害 −2 % |
| Falcon Gloves（手套） | 6,196 | 英雄 HP +2,021 · DEF +25 · **怪物伤害 −2.5 %** | 每档 受怪物伤害 −2 % |

- **最高 30 级**；三条额外属性分别在 Lv. 10、20、30 解锁。
- 规律：**武器 + 头盔 = 进攻**（ATK、对怪伤害），**护甲 + 手套 = 防御**（HP、减伤）。
- 全部强化到 Lv. 30 后，整套提供**对怪物伤害 +17 %** 和**受怪物伤害 −17 %**。
- 打造成本示例（武器）：紫色水晶 150 · 黄金 99,000。

## 4. 推荐步骤

| 步骤 | 操作 |
|------|------|
| 1 | **检查自动选择筛选**（齿轮图标）：设为「Blue or lower」，免得误拆紫色/橙色 |
| 2 | 用 Auto Select + Dismantle 熔掉旧装备 |
| 3 | 把多余的低阶材料往上合（Merge All），直到够下一次打造 |
| 4 | 把四个槽位都做到当前可得的最高品质，然后再去强化（为额外属性推到 Lv. 10/20/30） |

## 5. 联动

- **VIP 5** 提供**装备打造 +25 %**（见 VIP 手册）— 值得为此把大件打造攒着。
- 对怪物的伤害加成在 World Boss、Frenzied Boss 和雷达任务中生效。
- *打造是否在 Arms Race 中计分，活动说明未提及 — 请在活动界面确认。*
