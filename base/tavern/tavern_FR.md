# Outpost Tavern & Desert Treasure — Guide (Last Light)

## 1. Règles de base (Outpost Tavern)

- Un nombre fixe de missions de taverne par jour ; les héros sont envoyés **sans** être bloqués pour le reste du jeu.
- Plus le niveau de base est élevé, plus les étoiles des missions et les récompenses sont hautes.
- **Par équipe possédée, 2 missions de taverne tournent en même temps.**
- Les missions normales s'actualisent chaque jour à **0h00 (heure serveur)** ; les missions marquées d'un « like » ne s'actualisent que tous les 3 jours (et ne sont pas remplacées par une actualisation manuelle).

## 2. Qualité des missions & pillage

- Qualités : **Bleu < Violet < Orange** (meilleures récompenses).
- Actualisation manuelle avec des objets ou des diamants ; probabilités : **Bleu 68 % · Violet 24 % · Orange 8 %**.
- **Les non-alliés peuvent piller les récompenses de mission** — les alliés peuvent aider à terminer les missions pour empêcher le vol.

## 3. Desert Treasure (excavation de trésors)

- Les missions de taverne **violettes ou mieux** font tomber des **fragments de carte au trésor** aléatoires (7 types, M1–M7, tous équiprobables).
- Terminée sans pillage : chance d'**1 fragment bonus** — Violet **5 %**, Orange **15 %**.
- **1 excavation = 1 fragment de chaque type.** Échanger les fragments manquants avec les alliés (le fragment offert est temporairement déduit pendant l'échange).
- **Garantie Legendary :** après 15 excavations sans trésor Legendary, la **16e est garantie Legendary** ; le compteur se réinitialise à chaque drop Legendary.

## 4. Déroulé recommandé

| Étape | Action |
|-------|--------|
| 1 | Remplir chaque jour tous les créneaux de mission (2 par équipe) |
| 2 | Actualiser les missions bleues, viser Violet/Orange |
| 3 | Faire aider les alliés → protection contre le pillage + chance de fragment bonus |
| 4 | Obtenir les fragments manquants (M1–M7) par échange dans l'alliance |
| 5 | Excaver dès que les 7 fragments sont réunis — surveiller le compteur de garantie |

## 5. Checklist

- [ ] Toutes les missions de taverne du jour lancées (2 par équipe)
- [ ] Missions bleues actualisées (objectif : Violet/Orange)
- [ ] Aide de l'alliance demandée (protection contre le pillage)
- [ ] Échanges de fragments vérifiés (M1–M7 complets ?)
- [ ] Excavation faite, compteur de garantie (x/15) noté
