# Outpost Tavern と Desert Treasure — ガイド (Last Light)

## 1. 基本ルール（Outpost Tavern）

- 1日あたり決まった数の酒場ミッションがある。ヒーローは派遣されても、**他のプレイで使えなくなることはない**。
- 拠点レベルが高いほどミッションの星が高く、報酬も良くなる。
- **所持している部隊1つにつき、酒場ミッションが同時に2件走る。**
- 通常のミッションは毎日**サーバー時間 0:00** に更新。いいねアイコンの付いたミッションは3日ごとにしか更新されない（手動更新でも置き換わらない）。

## 2. ミッションの品質と略奪

- 品質: **青 < 紫 < オレンジ**（報酬が最良）。
- アイテムまたはダイヤで手動更新。確率: **青 68 % · 紫 24 % · オレンジ 8 %**。
- **同盟外のプレイヤーにミッション報酬を略奪されることがある** — 仲間にミッション完了を手伝ってもらえば盗難を防げる。

## 3. Desert Treasure（宝の発掘）

- **紫以上の酒場ミッション**からランダムに**宝の地図の欠片**が出る（7種類、M1〜M7、確率は均等）。
- 略奪されずに完了した場合、**欠片が1つ追加で出る確率** — 紫 **5 %**、オレンジ **15 %**。
- **発掘1回 = 各種類の欠片が1つずつ必要。** 足りない欠片は仲間と交換する（交換中は差し出した欠片が一時的に差し引かれる）。
- **Legendary 保証:** Legendary の宝が出ないまま15回発掘すると、**16回目は必ず Legendary**。カウンターは Legendary が出るたびにリセットされる。

## 4. 推奨手順

| 手順 | 内容 |
|------|------|
| 1 | 毎日すべてのミッション枠を埋める（部隊1つにつき2件） |
| 2 | 青のミッションは更新で流し、紫/オレンジを狙う |
| 3 | 仲間に手伝ってもらう → 略奪防止 + 追加欠片の確率を確保 |
| 4 | 足りない欠片（M1〜M7）は同盟内の交換で揃える |
| 5 | 7種すべて揃ったら発掘 — 保証カウンターを確認 |

## 5. チェックリスト

- [ ] 本日の酒場ミッションをすべて開始（部隊1つにつき2件）
- [ ] 青のミッションを更新で流した（狙いは紫/オレンジ）
- [ ] 同盟に支援を依頼（略奪防止）
- [ ] 仲間との欠片交換を確認（M1〜M7 は揃ったか）
- [ ] 発掘を実施し、保証カウンター（x/15）を控えた
