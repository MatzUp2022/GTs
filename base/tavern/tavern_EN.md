# Outpost Tavern & Desert Treasure — Guide (Last Light)

## 1. Ground Rules (Outpost Tavern)

- A set number of tavern missions daily; heroes are dispatched **without** being blocked for other gameplay.
- Higher base level = higher mission stars and better rewards.
- **Per team you own, 2 tavern missions run at the same time.**
- Common missions refresh daily at **0:00 server time**; missions marked with a like icon refresh only every 3 days (and are not replaced by manual refreshes).

## 2. Mission Quality & Plundering

- Qualities: **Blue < Purple < Orange** (best rewards).
- Manual refresh with items or diamonds; probabilities: **Blue 68 % · Purple 24 % · Orange 8 %**.
- **Non-allies can plunder mission rewards** — allies can help complete missions to prevent the theft.

## 3. Desert Treasure (Treasure Excavation)

- **Purple+ tavern missions** drop random **treasure map shards** (7 types, M1–M7, all equally likely).
- Completed without being plundered: chance of **1 extra shard** — Purple **5 %**, Orange **15 %**.
- **1 excavation = 1 shard of each type.** Trade missing shards with allies (the offered shard is temporarily deducted during an exchange).
- **Legendary guarantee:** after 15 excavations without a Legendary treasure, the **16th is guaranteed Legendary**; the counter resets on every Legendary drop.

## 4. Recommended Sequence

| Step | Action |
|------|--------|
| 1 | Fill every mission slot daily (2 per team) |
| 2 | Refresh blue missions, aim for Purple/Orange |
| 3 | Have allies help → plunder protection + secure the extra-shard chance |
| 4 | Get missing shards (M1–M7) via alliance trades |
| 5 | Excavate once all 7 shards are there — watch the guarantee counter |

## 5. Checklist

- [ ] All of today's tavern missions started (2 per team)
- [ ] Blue missions refreshed away (target: Purple/Orange)
- [ ] Alliance help requested (plunder protection)
- [ ] Shard trades with allies checked (M1–M7 complete?)
- [ ] Excavation done, guarantee counter (x/15) noted
