# Outpost Tavern 与 Desert Treasure — 指南 (Last Light)

## 1. 基本规则（Outpost Tavern）

- 每天有固定数量的酒馆任务；派出英雄**不会**占用他们在其他玩法中的使用。
- 基地等级越高，任务星级越高，奖励越好。
- **每拥有一支队伍，就有 2 个酒馆任务同时进行。**
- 普通任务每天**服务器时间 0:00** 刷新；带点赞图标的任务每 3 天才刷新一次（手动刷新也不会替换它们）。

## 2. 任务品质与掠夺

- 品质：**蓝 < 紫 < 橙**（奖励最好）。
- 用道具或钻石手动刷新；概率：**蓝 68 % · 紫 24 % · 橙 8 %**。
- **非盟友可以掠夺任务奖励** — 让盟友协助完成任务即可阻止被偷。

## 3. Desert Treasure（挖掘宝藏）

- **紫色及以上的酒馆任务**会随机掉落**藏宝图碎片**（7 种，M1–M7，概率均等）。
- 未被掠夺就完成时，有概率**额外掉落 1 个碎片** — 紫 **5 %**，橙 **15 %**。
- **挖掘 1 次 = 每种碎片各 1 个。** 缺的碎片和盟友交换（交换期间你提供的碎片会被暂时扣除）。
- **传说保底：** 连续 15 次挖掘没出传说宝藏，**第 16 次必出传说**；每次出传说后计数清零。

## 4. 推荐步骤

| 步骤 | 操作 |
|------|------|
| 1 | 每天把所有任务位填满（每队 2 个） |
| 2 | 把蓝色任务刷掉，争取紫色/橙色 |
| 3 | 请盟友协助 → 防掠夺 + 保住额外碎片的概率 |
| 4 | 缺的碎片（M1–M7）通过联盟交换补齐 |
| 5 | 7 种碎片齐了就挖 — 注意保底计数 |

## 5. 清单

- [ ] 今天的酒馆任务全部开启（每队 2 个）
- [ ] 蓝色任务已刷掉（目标：紫/橙）
- [ ] 已请求联盟协助（防掠夺）
- [ ] 已查看与盟友的碎片交换（M1–M7 齐了吗）
- [ ] 已完成挖掘，记下保底计数（x/15）
