# Research: Economy — Guide (Last Light)

## 1. Structure of the Tree

- Recurring blocks: **food + iron production** → **gold production** → **food/iron gathering** (pickaxe) → **gold gathering** → **milestone building** (e.g. farm, excavator) — then the next tier with the same techs at higher costs.
- Every tech has **5 levels**; milestones have **1 level** and unlock the next block (the next milestone in the tree is locked at 0/1).
- The third tier adds **%-output techs** for food, iron and gold.

## 2. Recommended Order

| Step | Action |
|------|--------|
| 1 | Production techs first — they work passively around the clock |
| 2 | Research the milestone as soon as the block is full (opens the next tier) |
| 3 | Follow up with gathering techs (pickaxe) if you actively farm the map |
| 4 | The third tier's %-output techs last |

## 3. Arms Race / SvS Link

- Completions count in the Arms Race **"Research Tech" phase at +1 point per tech CP** — finish economy researches there.
- Higher production feeds everything else: alliance contributions (Alliance Tech), construction and troops.

## 4. Checklist

- [ ] Both research slots busy (economy as filler between big researches)
- [ ] Milestones researched promptly (otherwise they block the whole tier)
- [ ] Completions placed into the Research Tech phase
