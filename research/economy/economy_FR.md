# Recherche : Economy — Guide (Last Light)

## 1. Structure de l'arbre

- Blocs récurrents : **production de nourriture + fer** → **production d'or** → **collecte nourriture/fer** (pioche) → **collecte d'or** → **bâtiment jalon** (p. ex. ferme, excavatrice) — puis le palier suivant avec les mêmes techs à coûts plus élevés.
- Chaque tech a **5 niveaux** ; les jalons ont **1 niveau** et débloquent le bloc suivant (le jalon suivant de l'arbre est verrouillé à 0/1).
- Le troisième palier ajoute des **techs de rendement en %** pour la nourriture, le fer et l'or.

## 2. Ordre recommandé

| Étape | Action |
|-------|--------|
| 1 | Les techs de production d'abord — elles agissent passivement en continu |
| 2 | Rechercher le jalon dès que le bloc est complet (ouvre le palier suivant) |
| 3 | Enchaîner les techs de collecte (pioche) si l'on farme activement la carte |
| 4 | Les techs de rendement en % du troisième palier en dernier |

## 3. Lien avec l'Arms Race / le SvS

- Les fins de recherche comptent dans la phase **« Research Tech » de l'Arms Race à +1 point par CP de tech** — y terminer les recherches d'économie.
- Une production plus élevée nourrit tout le reste : contributions d'alliance (Alliance Tech), construction et troupes.

## 4. Checklist

- [ ] Les deux créneaux de recherche occupés (l'économie comme bouche-trou entre les grosses recherches)
- [ ] Jalons recherchés rapidement (sinon ils bloquent tout le palier)
- [ ] Fins de recherche placées dans la phase Research Tech
