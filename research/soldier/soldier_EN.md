# Research: Soldier — Guide (Last Light)

## 1. Structure of the Tree

- Recurring blocks, **5 levels** per tech:
  **soldier ATK** (bullets) + **soldier DEF** (shield) → **soldier HP** (heart) → **load** (backpack) — then the next tier with the same techs at higher costs.
- Exact values are shown by the in-game popups (not included in the screenshots).

## 2. Recommended Order

| Step | Action |
|------|--------|
| 1 | Level the block's ATK + DEF first (combat power) |
| 2 | Follow with HP (fewer losses = less healing) |
| 3 | Load last (more loot per march, matters for gatherers & truck plundering) |

## 3. Links

- Completions count in the Arms Race **"Research Tech" phase at +1 point per tech CP**.
- Stronger soldiers matter directly in the **Region Duel** (Central City Clash: Lv. 8 kills score points) and in all rally events.

## 4. Checklist

- [ ] Current block finished (ATK/DEF → HP → load) before the next
- [ ] Completions placed into the Research Tech phase
- [ ] HP/DEF status checked before SvS weekends
