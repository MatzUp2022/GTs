# Research: Super Soldier — Guide (Last Light)

## 1. Structure of the Tree

- Techs here have **10 levels**; blocks: **HP / ATK / DEF Enhancement** (flat values per soldier) → **milestone** (officer emblem, diamond frame) → next block, extended by **training speed** and **capacity** techs (soldier with fast-forward or plus icon).
- **1-level milestones** (0/1, glowing soldier) sit at the block ends — unlocks; check the description in game.
- From **Super Soldier ≥ 40 %** (plus Lab Lv. 21) the Siege/Defense Specializations open (see the Development manual).

## 2. Values (example tier 1, 10 levels each)

| Tech | Effect Lv. 1 → 10 | CP Lv. 1 → 10 |
|------|-------------------|---------------|
| HP Enhancement (flat per soldier) | +15 → +150 | 2,625 → 37,323 |
| ATK Enhancement (flat) | +0.24 → +2.39 | 2,625 → 37,323 |
| DEF Enhancement (flat) | +0.05 → +0.48 | 2,625 → 37,323 |
| Premium Protection | +1.5 → 15 % | 4,039 → 67,503 |

*Premium Protection: exact effect not named in the screenshot — check in game.*

## 3. Priorities & Links

- Flat values apply **to every single soldier** — they scale with army size and pay off especially for large armies.
- Tree progress doubles as the **unlock condition** for the Specializations (≥ 40 %) — push it deliberately.
- Completions count in the Arms Race "Research Tech" phase (+1 point per CP).

## 4. Checklist

- [ ] The block's HP/ATK/DEF chain before the comfort techs
- [ ] Progress toward 40 % for the Specializations in sight
- [ ] Completions placed into the Research Tech phase
