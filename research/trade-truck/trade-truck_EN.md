# Research: Trade Truck — Guide (Last Light)

## 1. Structure of the Tree

- The tree carries the in-game **"Economy Rec."** marker.
- Building blocks (5 or 10 levels): **resource boost** (bread/iron/gold) → two **escort techs** (officer emblem with bullets/shield, 10 levels each) → **truck speed** (truck with clock) → **cargo +1** (crate +1) + **crate tech with fist icon** (protection/plunder — check the effect in game) → **+1 truck** (1 level) → ore-truck milestone (1 level).
- Value tables were not included in the screenshots — check the popups in game.

## 2. Recommended Order

| Step | Action |
|------|--------|
| 1 | Resource boost and truck speed first (more yield per run) |
| 2 | Escort techs next (protection against plundering) |
| 3 | Unlock cargo +1 and the 1-level milestones (+1 truck) |

## 3. Links

- **Region Duel (Mon–Fri):** plundering enemy region trucks grants **+100 region points** — your own trucks are targets in turn: escort and timing protect them.
- Completions count in the Arms Race "Research Tech" phase (+1 point per CP).

## 4. Checklist

- [ ] Truck runs started regularly (yield scales with the techs)
- [ ] Escort techs leveled before SvS weeks
- [ ] Milestones (+1 truck) unlocked promptly
- [ ] Completions placed into the Research Tech phase
