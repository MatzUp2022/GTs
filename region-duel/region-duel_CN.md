# Region Duel (SvS) — 指南 (Last Light)

## 1. 基本规则

- **两个区域（服务器）之间的 1v1 对决。** 胜利条件 = **占领对方的 Central City**。
- 多个区域被编入同一小组，打一场 **2–3 周**的锦标赛直到决出冠军区域（胜者打胜者，败者打败者）。
- 非赛季：随机匹配；赛季中：按赛季排名匹配。
- **团结是关键：** 同一区域的指挥官在中立建筑处不会互相攻击 — 他们是盟友（直接攻打基地除外）。

## 2. 每周节奏

| 时段 | 阶段 | 内容 |
|------|------|------|
| 周一至周五 | **积分争夺** | 赢下各项活动，累积区域积分 |
| 周五 | 结算 | 积分高的区域为**进攻方**，低的为**防守方** |
| 周六起 | **Central City Clash** | 进攻方可迁入敌方区域并夺取其 Central City |

## 3. 区域积分（周一至周五）

| 来源 | 积分 |
|------|------|
| **World Boss：** 总伤害最高的区域 | **+250,000** |
| **World Boss：** 个人伤害第 1 名 | **+150,000** |
| Alliance Duel 获胜 | +30,000 |
| Alliance Duel 的 MVP | +6,000 |
| Arms Race 第 1 名 | +2,000 |
| 掠夺敌方区域的卡车 | +100 |

→ **World Boss 主导整个计分**（每天最高 +400,000）— 见 World Boss 手册：SvS 期间它优先级最高。

## 4. Central City Clash（周六起）

**个人积分来源（节选）：**

| 行为 | 积分 |
|------|------|
| 打翻敌方指挥官的基地 | +50,000 |
| 在 Central City / Giant Battery 击杀 8 级士兵 | +54 |
| 在 Polluted Zone 击杀 8 级士兵 | +27 |
| 在一般区域击杀 8 级士兵 | +9 |
| 使敌方基地防御点数降低 1 | +10 |
| 驻防 Giant Battery / Central City（按秒计，返回时结算） | +25 |

- 区域的**连胜奖励**需要**个人积分 50,000** — 这是所有人的最低参与线。
- 个人积分宝箱从 **125,000 / 250,000 / 375,000** 分起。
- 防守方：守住并驻防 Central City；进攻方：集体迁城并拿下 Central City。
