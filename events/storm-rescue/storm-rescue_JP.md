# Storm Rescue — ガイド (Last Light)

## 1. 基本ルール

- 1回の挑戦は**5ステージ**。各ステージ後に、進むか抜けるかを選ぶ。
- **注意:** 途中で抜けると、次の挑戦は**またステージ1から始まる**。
- **5ステージ連続クリア、またはステージ敗北**で → ステージの清算。

## 2. 挑戦回数の使い方

- **イベントステージを3つクリアすれば、アチーブメント報酬はすべて揃う** — それ以上は不要。
- 自分から抜けないこと。ステージ1からやり直すのは時間の無駄でしかない。
- → 清算が来るまで進み続ける（5クリア、または最初の敗北）。

## 3. 推奨手順

| 手順 | 内容 |
|------|------|
| 1 | チャレンジを開始し、ステージを一気に進める — 途中で抜けない |
| 2 | 行けるところまで行く。敗北すれば清算とともに終了する |
| 3 | 1 / 2 / 3 ステージ分のアチーブメント報酬を受け取る |

## 4. 報酬

| クリアステージ数 | 報酬（一部） |
|------------------|--------------|
| 1 | バッジ2 · EXP宝箱6 · コイン宝箱6 · ジェム20 |
| 2 | 3 · 12 · 12 · ジェム30 |
| 3 | 5 · 3 · 3 · ジェム50 |

- イベント画面の合計表示には次が含まれる: バッジ10 · EXP宝箱18 · コイン宝箱18 · **ジェム100**。

*SvS などとの連動: イベント情報には記載なし。*

## 5. チェックリスト

- [ ] チャレンジを開始し、抜けずに最後までプレイした
- [ ] 3ステージ以上クリアした
- [ ] アチーブメント報酬を3つとも受け取った
- [ ] イベント画面で残り時間を確認した
