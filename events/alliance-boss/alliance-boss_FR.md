# Boss d'Alliance — Guide d'événement (Last Light)

## 1. Phases & déroulé

| Phase | Ce qui se passe |
|-------|-----------------|
| Sélection | Les R4/R5 choisissent la difficulté + l'heure de début — **min. 20 membres** requis |
| Préparation | Tout le monde donne des ressources → récompenses de contribution + bonus de dégâts ; les dons continuent même après les objectifs atteints |
| Bataille | **30 minutes** ; lancée manuellement par un R4/R5, sinon démarrage auto 30 min avant le reset du serveur ; l'autel disparaît et invoque des Démons |
| Règlement | Récompenses selon les dégâts totaux de l'alliance et les dégâts personnels |

## 2. Règles de base

- Les Démons ne peuvent être attaqués **que par rally** — pas d'attaques solo.
- Les rallys lancés par un **R4 ou plus** reçoivent un **bonus de dégâts supplémentaire** → privilégier leurs rallys.
- **Activer Join Offline** pour que les troupes combattent même hors ligne.
- **Dons à l'autel :** 1 don = **×500 contribution d'alliance** ; bonus de l'autel au niv. 5 = **+25 % de dégâts** sur le Boss d'Alliance (niveau max).
- Des dégâts totaux d'alliance plus élevés débloquent des **difficultés supérieures** (p. ex. niv. 6 avec un meilleur aperçu des récompenses).

## 3. Mécanique MVP

- Le joueur avec les **dégâts personnels les plus élevés** multiplie les récompenses d'alliance par **×1–10** (selon ses dégâts) — jusqu'à **Reward ×10**.
- → Les joueurs les plus forts visent le dégât maximal ; les autres remplissent les rallys.
