# Vehículo (Armored Warmachine) — Guía (Last Light)

## 1. Reglas básicas

- El vehículo **ataca continuamente durante el combate y no puede ser atacado**.
- Los atributos del vehículo se convierten hacia los **héroes del equipo** según una **tasa de conversión** (p. ej. 15 % cada uno de ATQ/PV/DEF) — el vehículo escala a todo el equipo.
- **Skins (Appearance):** los estilos equipados y los simplemente poseídos dan bonos pasivos (p. ej. +5 % de daño a monstruos equipado; poseídos incl. +8 % ATQ de héroes, +5 % PV de héroes) — los skins rinden incluso sin usar.

## 2. Subida de nivel y crítico de EXP

- Se sube con **objetos de EXP**; barra llena = subida de nivel con mejores atributos.
- **Crítico de EXP:** mientras la barra está **por debajo del 80 %** hay **50 % de probabilidad de EXP doble**; desde el 80 % no hay críticos, tampoco en los avances de fase. → Alimentar la EXP en tandas por debajo del 80 %.
- **Los niveles de habilidad suben automáticamente** en los niveles de vehículo **30 / 50 / 70 / 90 / 110**.

## 3. Habilidad: Global Strike

- Base: **426 % del ATQ** como daño físico a 2 enemigos.

| Estrella | Efecto |
|----------|--------|
| ★1 | El objetivo recibe +15 % de daño durante 1 turno |
| ★2 | +20 % de daño físico extra |
| ★3 | El objetivo recibe +20 % de daño durante 1 turno |
| ★4 | +40 % de daño físico extra (vehículo nv. 90) |
| ★5 | El objetivo recibe +25 % de daño durante 1 turno (nv. 110) |

## 4. Módulos (desde base nv. 15)

- **6 módulos**, uno por hueco; una mejora requiere **2× un módulo del mismo nivel** (3 módulos idénticos se fusionan en uno de mayor calidad; «Conversion Materials» convierte los sobrantes).

| Módulo | Valor (ejemplo nv. 6 → 7) |
|--------|---------------------------|
| CPU | PV del vehículo 80.025 → 202.939 |
| Engine | ATQ del vehículo 3.811 → 9.664 |
| Tire | DEF del vehículo 762 → 1.933 |
| Radar | PV de héroes 42.195 → 92.244 |
| Armor | DEF de héroes 401 → 878 |
| Turret | ATQ de héroes 2.009 → 4.392 · daño de habilidad 2,5 → 3,5 % |

- Las mejoras dan saltos grandes (hasta ×2,5) — prioridades: **Turret** (ATQ de héroes + daño de habilidad) y **Radar** (PV de héroes).

## 5. Perspectiva: Battle Advancement y Skill Core (desde el día 82 del servidor)

- **Battle Advancement** mejora aún más el vehículo; con **BA nv. 10** se abre el sistema **Skill Core**.
- Por plan de core: **1 habilidad de apertura + 1 de ataque + 1 de disrupción + 1 de defensa**; elegir el plan antes del combate.
- Subir estrellas de cores excelentes/legendarios consumiendo cores idénticos; los cores sin usar alimentan el Battle Advancement; cada avance de fase aumenta la **Skill Amplification**.
