# Véhicule (Armored Warmachine) — Guide (Last Light)

## 1. Règles de base

- Le véhicule **attaque en continu pendant le combat et ne peut pas être attaqué**.
- Les attributs du véhicule sont convertis vers les **héros de l'équipe** selon un **taux de conversion** (p. ex. 15 % chacun pour ATQ/PV/DÉF) — le véhicule renforce toute l'équipe.
- **Skins (Appearance) :** les styles équipés et simplement possédés donnent des bonus passifs (p. ex. +5 % de dégâts aux monstres équipé ; possédés dont +8 % ATQ héros, +5 % PV héros) — les skins rapportent même inutilisés.

## 2. Montée de niveau & crit d'EXP

- Montée via des **objets d'EXP** ; barre pleine = niveau supérieur avec de meilleurs attributs.
- **Crit d'EXP :** tant que la barre est **sous 80 %**, il y a **50 % de chances d'EXP doublée** ; à partir de 80 % pas de crit, ni pendant les percées de phase. → Nourrir l'EXP par rafales sous 80 %.
- **Les niveaux de compétence montent automatiquement** aux niveaux de véhicule **30 / 50 / 70 / 90 / 110**.

## 3. Compétence : Global Strike

- Base : **426 % de l'ATQ** en dégâts physiques sur 2 ennemis.

| Étoile | Effet |
|--------|-------|
| ★1 | La cible subit +15 % de dégâts pendant 1 tour |
| ★2 | +20 % de dégâts physiques supplémentaires |
| ★3 | La cible subit +20 % de dégâts pendant 1 tour |
| ★4 | +40 % de dégâts physiques supplémentaires (véhicule niv. 90) |
| ★5 | La cible subit +25 % de dégâts pendant 1 tour (niv. 110) |

## 4. Modules (dès base niv. 15)

- **6 modules**, un par emplacement ; une amélioration demande **2× un module du même niveau** (3 modules identiques fusionnent en un module de qualité supérieure ; « Conversion Materials » convertit les restes).

| Module | Valeur (exemple niv. 6 → 7) |
|--------|------------------------------|
| CPU | PV du véhicule 80 025 → 202 939 |
| Engine | ATQ du véhicule 3 811 → 9 664 |
| Tire | DÉF du véhicule 762 → 1 933 |
| Radar | PV des héros 42 195 → 92 244 |
| Armor | DÉF des héros 401 → 878 |
| Turret | ATQ des héros 2 009 → 4 392 · dégâts de compétence 2,5 → 3,5 % |

- Les améliorations font des bonds (jusqu'à ×2,5) — priorités : **Turret** (ATQ héros + dégâts de compétence) et **Radar** (PV héros).

## 5. Perspective : Battle Advancement & Skill Core (dès le jour 82 du serveur)

- **Battle Advancement** renforce encore le véhicule ; au **niv. 10 de BA**, le système **Skill Core** s'ouvre.
- Par plan de core : **1 compétence d'ouverture + 1 d'attaque + 1 de perturbation + 1 de défense** ; choisir le plan avant le combat.
- Étoiler les cores excellents/légendaires en consommant des cores identiques ; donner les cores inutilisés au Battle Advancement ; chaque percée de phase augmente la **Skill Amplification**.

## 6. Checklist

- [ ] EXP donnée sous 80 % de barre (chance de crit)
- [ ] Niveaux visés sur les seuils de compétence 30/50/70/90/110
- [ ] Modules Turret et Radar priorisés ; 3 modules identiques fusionnés
- [ ] Skins collectés (bonus passifs même inutilisés)
- [ ] Dès le jour 82 : nourrir le Battle Advancement, plan de core choisi avant le combat
