# Boss Mondial — Escouade d'événement (Last Light)

## 1. Règles de composition
- **Aucun héros de défense / bouclier** — le boss ne meurt pas, la survie n'a aucune importance. Dégâts purs.
- **Uniquement le meilleur équipement doré** sur les héros choisis. Équiper avant la première attaque, pas entre les runs.
- **Vérifier le bonus du jour :** quel type de héros bénéficie aujourd'hui de **+50 % d'avantage** → prioriser ce type.
- Composition **réservée à l'événement**, pas l'escouade de rally standard.

## 2. Économie des attaques
- **5 attaques par jour.**
- **3 attaques** donnent en plus des **récompenses spéciales** → ne jamais les laisser expirer.
- **Seule l'attaque au plus haut dégât compte** pour le classement.
- → Ne pas lancer 5 fois la même composition. Chaque run sans variation est une information perdue.

## 3. Déroulé recommandé

| Attaque | Objectif | Composition |
|---------|----------|-------------|
| 1 | Référence | Meilleure composition connue, type bonus inclus |
| 2 | Variante A | Un héros remplacé (renforcer le type bonus) |
| 3 | Variante B | Variation de compétences / équipement vs référence |
| 4 | Consolidation | La meilleure des attaques 1–3, avec correction fine |
| 5 | Run maximal | Tous les buffs et boosts sur la composition gagnante |

**Règle :** ne pas répartir les buffs, objets de rage et boosters sur les runs de test — tout concentrer sur le run maximal.

## 4. Lien avec le SvS
- **+250 000** — serveur avec les dégâts totaux les plus élevés (classement quotidien)
- **+150 000** — serveur détenant le MVP (dégâts individuels les plus élevés)
- **Total : jusqu'à +400 000 points par jour**

Toutes les autres tâches quotidiennes rapportent nettement moins et **ne peuvent pas compenser** une journée de Boss Mondial perdue.

→ Le Boss Mondial est **prioritaire** pendant le SvS. Les ressources prévues pour d'autres objectifs quotidiens sont redirigées ici si nécessaire.

## 5. Checklist quotidienne
- [ ] Type bonus du jour vérifié
- [ ] Héros de défense retirés
- [ ] Équipement doré complet
- [ ] Buffs réservés pour l'attaque 5
- [ ] Les 5 attaques utilisées, au moins 3 compositions variées
