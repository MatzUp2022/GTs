# Boutiques — Diamond Store & Co. (Last Light)

## 1. Aperçu

- Barre des boutiques en jeu : **Diamond Store · VIP Shop · Alliance Store · Honor Store** (…).
- Le **Goods Refresh Ticket** (100 diamants) renouvelle l'offre.

## 3. Évaluation

- **Les ressources sont bon marché** (50 diamants chacune) — utiles en complément avant les phases d'Arms Race.
- **Déménagements :** pour rejoindre l'alliance, l'**Alliance Relocation (500)** suffit — trois fois moins chère que la Premium Relocation à placement libre (1 500). Important pour le **Region Duel** (samedi : déplacement dans la région ennemie).
- Comparer les tickets de recrutement (400 chacun) avec les offres d'événement avant d'acheter ici.

## 4. Checklist

- [ ] Budget de diamants réservé aux déménagements SvS (Alliance Relocation)
- [ ] Achats de ressources placés dans la bonne phase d'Arms Race
- [ ] Boutiques VIP/Alliance/Honor vérifiées régulièrement
