# VIP System — Guide (Last Light)

## 1. Ground Rules

- VIP levels rise via **VIP EXP**: daily **login streak** (e.g. 200 EXP/day on a 45-day streak), plus purchasable EXP ("+") and monthly card / VIP packs.
- Privileges are **cumulative** — every level keeps all previous perks and improves some of them.
- Claim daily: the **daily chest** (VIP bar) and the **VIP daily free pack** (grows with the level, e.g. VIP11: 1 puzzle + 11 of each resource chest) — expires after 24 h.
- Each level has a one-time **exclusive pack** (purchase limit 1); there is also a **VIP shop**.

## 3. Key Milestones

- **VIP 4:** tavern auto dispatch — tavern missions run without manual assignment.
- **VIP 8:** second Faction Trial quick battle + march +10 %.
- **VIP 10:** first real combat perks (hero HP/ATK/DEF +2.5 %, healing +10 %).
- **VIP 12:** Outpost Tavern super mode + hero stats +5 %.

## 4. Checklist (daily)

- [ ] Logged in (login streak = VIP EXP)
- [ ] Daily chest on the VIP bar opened
- [ ] VIP daily free pack claimed (expires!)
- [ ] VIP shop checked for offers
