# Help & FAQ — Guide (Last Light)

*Dans le jeu via le profil → **Help** (onglets : Home · Settings · Help) ; le bouton **Feedback** y contacte le service client.*

## 1. Jeu & technique

| Problème | Solution |
|----------|----------|
| Changement d'appareil | Installer le jeu, se connecter avec compte + mot de passe sur l'écran de connexion |
| Compte volé / mot de passe changé | **Contacter immédiatement le service client** |
| Timeout de connexion | Se reconnecter ou redémarrer le jeu |
| Jeu bloqué en mise à jour | Fermer l'appli ou changer de réseau, relancer ; sinon service client |
| Données de jeu « perdues » | **Vérifier le bon serveur** — les données ne sont pas partagées entre serveurs ; sinon contacter le support avec ID de jeu + nom de compte |
| Déconnexions fréquentes | Vérifier le réseau ; sinon service client |
| Plantages | Fermer et rouvrir l'appli ; redémarrer l'appareil ; sinon service client |
| Tricheur repéré | Le signaler rapidement (service client) |

## 2. Social & alliance

- **Pub/fraude dans le chat :** signaler au service client avec l'ID de compte du joueur.
- **Rejoindre une alliance :** construire l'Alliance Center → choisir une alliance recommandée ou chercher par ID → envoyer une candidature ; ou créer la sienne.
- **Changer d'alliance :** pendant certains événements, un changement peut **coûter l'éligibilité aux récompenses** — ne pas changer en plein événement !
- **Alliance Tech :** les contributions en or ou diamants remplissent la barre d'EXP ; une fois pleine, l'alliance peut rechercher la technologie.
- **Alliance Help :** les alliés accélèrent constructions, recherches et soins des soldats — donner et demander de l'aide.

## 3. Achats (recharge)

- **VIP :** via le statut VIP ou les packs carte mensuelle ; VIP plus élevé = plus d'avantages.
- **Premier achat :** débloque des héros S+ ultra-rares, des tickets de recrutement ×10 et d'autres offres.
- **Payé mais rien reçu :** redémarrer le jeu ; si rien n'arrive → service client.
- **Montant différent :** conversion dans la devise locale, le taux de change peut fluctuer.

## 4. Pense-bête pour l'alliance

- [ ] Compte sécurisé par mot de passe (important pour changer d'appareil)
- [ ] Numéro de serveur noté (p. ex. #149)
- [ ] Pas de changement d'alliance pendant un événement en cours
- [ ] Alliance Help utilisée chaque jour (donner + demander)
- [ ] Problèmes signalés via le bouton Feedback
