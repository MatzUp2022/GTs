# Frenzied Boss — Руководство (Last Light)

## 1. Основные правила

- Серверное событие: **три босса** приходят через порталы у Central City — по одному в **0:00, 6:00 и 12:00 по времени сервера**.
- Нужен **уровень базы 5+**; в одиночку их не одолеть — сражается весь сервер.
- У каждого босса свои слабости — атака по ним наносит заметно больше урона.
- В **24:00 по времени сервера** все непобеждённые боссы **сбегают** — нанесите урон до этого.

## 2. Экономия попыток

- **Атак неограниченно**, но в общий зачёт идут только **3 попытки с наибольшим уроном**.
- → Сначала свободно пробуйте, затем сделайте **3 максимальных захода** со всеми бафами.
- Когда босс **ослаблен** (получил достаточно урона): сразу забирайте награды; рекорд урона для рейтинга можно улучшать и после.
- **All-Out Attack** (открывается поэтапно): все отряды бьют одновременно — используйте для концентрированного урона.

## 3. Рекомендуемый порядок

| Босс | HP (ур. 1) | +50 % урона от |
|------|------------|----------------|
| Giant Zombie | 40G | фракция **Guardian** |
| Undead Zombie | 30G | фракция **Ranger** |
| Frenzied Zombie | 25G | фракция **Berserker** |

- Пересобирайте состав **под каждого босса** вокруг его слабой фракции — не гоняйте всех троих одной стандартной командой.
- Ставьте 3 зачётных захода туда, где ваша фракция сильнее всего; порог рейтинга (100-е место) смотрите на экране события.

## 4. Награды и цель сервера

- **Участие:** все, кто нанёс урон, получают награды **по почте** — больше урона, лучше награды.
- **Топ-100** командиров по суммарному урону получают дополнительные рейтинговые награды.
- **Все 3 босса побеждены** → в следующем событии боссы сильнее и награды лучше; **ни один не побеждён** → боссы слабее, а более богатые последующие награды недоступны.

*Связь с SvS или чем-то подобным: в описании события не указана.*

## 5. Чек-лист

- [ ] Время появления 0/6/12 по серверу учтено в планах
- [ ] Состав пересобран под слабую фракцию каждого босса
- [ ] Сначала свободные пробы, затем 3 максимальных захода с бафами
- [ ] Награды за ослабленного босса забраны
- [ ] Урон нанесён всем трём боссам до 24:00 (награда по почте)
