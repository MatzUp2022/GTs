# Peak Arena — ガイド (Last Light)

## 1. 基本ルール

- **毎週火曜**に開幕。対戦は3日間続き、金曜のあとに終了。**オフシーズンは土〜月**。
- 参加資格: サーバー内 **Total Hero CP 上位200名** — 自動判定で、CPが条件を満たせば途中参加も可能。
- 各ラウンドには **1〜4リージョン**のコマンダーが含まれる。
- 初期順位は参加時のCPで決まる。

## 2. 戦闘とランキング

- 各チャレンジで複数の相手が提示される。自分より上位の相手に勝つと → **順位が入れ替わる**。
- **1日のチャレンジ回数は限られている** — 安全な小勝を拾うより、できるだけ上を狙う。
- シーズン報酬は金曜の対戦終了後に配布される。

## 3. 防衛

- 初期防衛は最強のサンドボックス編成。開始後に Defense メニューで変更できる。
- Peak Arena の防衛編成は**別枠で保存**され、他の編成には影響しない。

## 4. 報酬

- **デイリー:** 1 / 3 / 5 勝で勝利宝箱（Challenge 画面）。
- **シーズン:** 最終順位に応じた報酬を金曜に配布。

## 5. チェックリスト

- [ ] 火曜: 参加資格を確認（ヒーローCPで上位200位内か）
- [ ] デイリーのチャレンジを使い切った（回数制限あり）
- [ ] 順位入れ替えを狙って上位の相手に挑んだ
- [ ] 防衛編成を別途整備した
- [ ] 勝利宝箱のために毎日 1/3/5 勝
