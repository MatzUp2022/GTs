# Peak Arena — 指南 (Last Light)

## 1. 基本规则

- **每周二**开启；对战持续 3 天，周五之后结束；**休赛期为周六至周一**。
- 参赛资格：全服 **Total Hero CP 前 200 名** — 自动判定；只要 CP 达标，中途也能加入。
- 每一轮包含来自 **1–4 个区域**的指挥官。
- 初始排名依据你进入时的 CP。

## 2. 战斗与排名

- 每次挑战会给出多个对手。击败排名更高的对手 → **双方名次互换**。
- **每日挑战次数有限** — 要尽量往高处打，而不是攒安全的小胜。
- 赛季奖励在周五对战结束后发放。

## 3. 防守

- 默认防守阵容为你最强的沙盒队伍；开赛后可在 Defense 菜单调整。
- Peak Arena 的防守阵容**单独保存**，不影响你的其他队伍。

## 4. 奖励

- **每日：** 1 / 3 / 5 胜后的胜利宝箱（Challenge 界面）。
- **赛季：** 按最终排名发放，周五结算。

## 5. 清单

- [ ] 周二：确认参赛资格（英雄 CP 是否在前 200）
- [ ] 每日挑战次数已用完（有限！）
- [ ] 已挑战排名更高的对手以换取名次
- [ ] 防守阵容单独维护
- [ ] 每日 1/3/5 胜以拿齐胜利宝箱
