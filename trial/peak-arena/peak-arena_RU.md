# Peak Arena — Руководство (Last Light)

## 1. Основные правила

- Открывается **каждый вторник**; матчи идут 3 дня и закрываются после пятницы; **межсезонье сб–пн**.
- Допуск: **топ-200 игроков сервера по Total Hero CP** — автоматически; подключиться по ходу можно, как только ваш CP проходит.
- В каждом раунде участвуют командиры из **1–4 регионов**.
- Стартовое место в таблице определяется вашим CP на момент входа.

## 2. Бой и рейтинг

- В каждом вызове предлагается несколько противников. Победа над тем, кто стоит выше → **места меняются местами**.
- **Число вызовов в день ограничено** — целитесь как можно выше, а не собирайте безопасные мелкие победы.
- Сезонные награды выдаются в пятницу после окончания матчей.

## 3. Оборона

- Оборона по умолчанию — ваша сильнейшая команда из песочницы; после старта настраивается в меню Defense.
- Оборона Peak Arena **сохраняется отдельно** и не влияет на остальные команды.

## 4. Награды

- **Ежедневно:** сундуки за 1 / 3 / 5 побед (экран Challenge).
- **Сезон:** награды по итоговому месту, выдаются в пятницу.

## 5. Чек-лист

- [ ] Вторник: проверен допуск (топ-200 по CP героев?)
- [ ] Дневные вызовы израсходованы полностью (их мало!)
- [ ] Атакованы противники выше по рейтингу ради обмена местами
- [ ] Команда обороны поддерживается отдельно
- [ ] 1/3/5 побед ежедневно ради сундуков
