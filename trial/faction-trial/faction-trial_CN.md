# Faction Trial — 指南 (Last Light)

## 1. 基本规则

- 三个试炼：**Guardian、Ranger、Berserker** — 在各自的试炼中，对应阵营造成 **+50 % 伤害**。
- 进度**每周二 / 四 / 日**重置。
- 难度可选，但：**每个周期只能选一个难度，选定后不可更改。**
- **每个英雄只能参加一个试炼** — 必须把阵容拆成三份。
- **免费加成：** 试炼阵容本来就是纯阵营，因此 **+20 % HP/ATK/DEF** 的编队加成自动生效。

## 2. 推荐步骤

| 步骤 | 操作 |
|------|------|
| 1 | 提前把阵容分成三支阵营队伍（同一英雄不重复） |
| 2 | 每个试炼的难度都要斟酌 — 查看敌方 CP（例如 Lv. 16 ≈ 9.2M），在稳妥范围内尽量选高 |
| 3 | 在各自的重置前把三个试炼都打完 |
| 4 | 领取成就并查看商店商品 |

- 提示：这三支阵营队伍正好对应 Frenzied Boss 活动中 Boss 的弱点（Guardian/Ranger/Berserker）— 直接复用阵容。

## 3. 奖励

- 「Total Rewards for Clearing」随难度提升（例如每次通关 25 个 EXP/铁/面包宝箱 + 5 个特殊宝箱）。
- 每个试炼都有**排行榜**，另有**成就**宝箱和**商店**。

## 4. 清单

- [ ] 已规划三支阵营队伍（没有英雄同时进两个试炼）
- [ ] 每个试炼都选好难度（周期内不可改！）
- [ ] 重置前已完成 Guardian、Ranger、Berserker 三个试炼
- [ ] 已查看成就与商店
