# Faction Trial — ガイド (Last Light)

## 1. 基本ルール

- 3つのトライアル: **Guardian, Ranger, Berserker** — 各トライアルでは対応する陣営が **+50 % DMG**。
- 進行度は**毎週 火・木・日**にリセットされる。
- 難易度は選べるが、**1サイクルにつき1段階のみ、あとから変更できない**。
- **各ヒーローは1つのトライアルにしか参加できない** — 手持ちを3つに割り振る必要がある。
- **無料のボーナス:** トライアルの編成はどのみち単一陣営になるため、編成ボーナス **+20 % HP/ATK/DEF** が自動的に乗る。

## 2. 推奨手順

| 手順 | 内容 |
|------|------|
| 1 | 手持ちをあらかじめ3つの陣営編成に分ける（同じヒーローを二重に使わない） |
| 2 | 各トライアルの難易度は慎重に — 敵のCP（例: Lv. 16 ≈ 9.2M）を確認し、安全な範囲で最大を選ぶ |
| 3 | それぞれのリセット前に3つのトライアルを終わらせる |
| 4 | アチーブメントを回収し、ストアの品揃えを確認 |

- ヒント: 3つの陣営編成は Frenzied Boss イベントのボス弱点（Guardian/Ranger/Berserker）と一致する — 同じ編成を使い回す。

## 3. 報酬

- 「Total Rewards for Clearing」は段階とともに増える（例: クリアごとに EXP/鉄/パンの宝箱25 + 特別宝箱5）。
- 各トライアルに**ランキング**、**アチーブメント**宝箱、**ストア**がある。

## 4. チェックリスト

- [ ] 3つの陣営編成を用意（同じヒーローが2つのトライアルに入っていない）
- [ ] トライアルごとに難易度を選択（サイクル中は変更不可）
- [ ] リセット前に Guardian・Ranger・Berserker のトライアルを実施
- [ ] アチーブメントとストアを確認
