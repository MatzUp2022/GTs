# Faction Trial — Руководство (Last Light)

## 1. Основные правила

- Три испытания: **Guardian, Ranger, Berserker** — в каждом соответствующая фракция наносит **+50 % урона**.
- Прогресс сбрасывается **каждую неделю во вт / чт / вс**.
- Сложность выбирается, но: **только один уровень за цикл, и изменить его потом нельзя.**
- **Каждый герой может участвовать лишь в одном испытании** — состав приходится делить на три части.
- **Бесплатный бонус:** поскольку каждая команда испытания и так монофракционная, бонус построения **+20 % HP/ATK/DEF** действует автоматически.

## 2. Рекомендуемый порядок

| Шаг | Действие |
|-----|----------|
| 1 | Заранее разделить состав на три фракционные команды (ни одного героя дважды) |
| 2 | Сложность каждого испытания выбирать осознанно — посмотреть CP противника (например, ур. 16 ≈ 9,2M) и брать максимум, который безопасен |
| 3 | Пройти все три испытания до соответствующего сброса |
| 4 | Забрать достижения и посмотреть предложения магазина |

- Совет: три фракционные команды совпадают со слабостями боссов в событии Frenzied Boss (Guardian/Ranger/Berserker) — используйте те же составы.

## 3. Награды

- «Total Rewards for Clearing» растут с уровнем (например, 25 сундуков EXP/железа/хлеба + 5 особых сундуков за прохождение).
- У каждого испытания есть **таблица лидеров**, а также сундуки за **достижения** и **магазин**.

## 4. Чек-лист

- [ ] Три фракционные команды распланированы (ни один герой не в двух испытаниях)
- [ ] Сложность выбрана для каждого испытания (в течение цикла не меняется!)
- [ ] Испытания Guardian, Ranger и Berserker пройдены до сброса
- [ ] Достижения и магазин проверены
