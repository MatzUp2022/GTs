# 3V3 Arena — ガイド (Last Light)

## 1. 基本ルール

- サーバー間イベント（例: #147/#149/#151/#154）。1回の開催につき **14日間**。
- 参加資格: サーバー内 **Total Hero CP 上位200名** — 自動判定で、CPが条件を満たせば途中参加も可能。
- 全員 **1,000ポイント**から開始。初期順位は Total Hero CP による。

## 2. ポイントと戦闘

- 各チャレンジで複数の相手が提示される。勝利でポイント獲得（**ポイントが高い相手ほど多い**）、敗北で減点（**ポイントが低い相手ほど多く減る**）。
- **3本勝負:** 自分の攻撃編成3つ対、相手の防衛編成3つ。
- 最終順位はポイントで決まる。

## 3. 防衛

- 初期防衛は部隊1・2・3。開始後に Defense メニューで変更できる。
- アリーナの防衛編成は**別枠で保存**され、他の編成には影響しない。

## 4. 報酬

- **デイリー:** 1 / 3 / 5 勝で勝利宝箱（ダイヤ50〜100、メダル、宝箱、スタミナなど）。
- **シーズン順位（抜粋）:**

| 順位 | 報酬（一部） |
|------|--------------|
| 1 | タレットスキン · ギフト3 · スタミナ3,000 · メダル30K |
| 2 | タレット ×1 · 2 · 2,000 · 25K |
| 3 | タレット ×1 · 2 · 1,500 · 20K |
| 4–10 | タレット ×1 · 1 · 1,000 · 15K |
| 11–20 | タレット ×1 · 1 · 950 · 14K |
| 21–40 | ギフト3 · スタミナ900 · 13K · ダイヤ3,000 |
| 41–70 | 2 · 850 · 12K · ダイヤ3,000 |

- **同盟報酬:** 上位10名にコマンダーを送り込んだ同盟は、終了時に追加報酬を受け取る（各段階は1回のみ。1位は スタミナ1,000 + 150の宝箱 など）。

## 5. チェックリスト

- [ ] 3本勝負を見据えて攻撃編成3つを練った
- [ ] アリーナ防衛を整備（別枠保存）
- [ ] ポイントの高い相手を優先して攻撃
- [ ] まだ上位200位に入っていなければCPを伸ばす
