# 3V3 Arena — Руководство (Last Light)

## 1. Основные правила

- Межсерверное событие (например, #147/#149/#151/#154), каждое открытие длится **14 дней**.
- Допуск: **топ-200 игроков сервера по Total Hero CP** — автоматически; подключиться по ходу можно, как только ваш CP проходит.
- Все стартуют с **1 000 очков**; начальный рейтинг — по Total Hero CP.

## 2. Очки и бои

- В каждом вызове предлагается несколько противников. Победа = очки (**больше против соперников с бо́льшим счётом**); поражение = вычет (**больше против соперников с меньшим счётом**).
- **Best-of-three:** ваши 3 атакующие команды против 3 оборонительных команд соперника.
- Итоговое место определяется очками.

## 3. Оборона

- Оборона по умолчанию — отряды 1, 2 и 3; после старта настраивается в меню Defense.
- Оборона арены **сохраняется отдельно** и не влияет на остальные команды.

## 4. Награды

- **Ежедневно:** сундуки за 1 / 3 / 5 побед (в том числе 50–100 алмазов, медали, сундуки, энергия).
- **Сезонный рейтинг (выдержка):**

| Место | Награды (в том числе) |
|-------|-----------------------|
| 1 | Скин турели · 3 подарка · 3 000 энергии · 30K медалей |
| 2 | Турель ×1 · 2 · 2 000 · 25K |
| 3 | Турель ×1 · 2 · 1 500 · 20K |
| 4–10 | Турель ×1 · 1 · 1 000 · 15K |
| 11–20 | Турель ×1 · 1 · 950 · 14K |
| 21–40 | 3 подарка · 900 энергии · 13K · 3 000 алмазов |
| 41–70 | 2 · 850 · 12K · 3 000 алмазов |

- **Награды альянсу:** альянсы с командирами в топ-10 получают в конце дополнительные награды (каждая ступень только один раз; 1-е место — в том числе 1 000 энергии + сундук на 150).

## 5. Чек-лист

- [ ] 5 побед в день ради всех сундуков
- [ ] 3 атакующие команды продуманно собраны под best-of-three
- [ ] Оборона арены поддерживается (сохраняется отдельно)
- [ ] Предпочтительно атаковать соперников с бо́льшим счётом
- [ ] Поднимать CP, если ещё не в топ-200
