# Adventure — 关卡推图与挂机收益 (Last Light)

## 1. 基本规则

- 一张连续的**关卡地图**；**Challenge** 用你上阵的五名英雄开始当前关卡的战斗。
- 战斗前顶部会显示双方 **CP**（第 308 关示例：你的 8.74M 对 4.49M）— 判断这一关能不能过的最佳依据。
- 阵容界面的图标可按 **ALL / Guardian / Ranger / Berserker** 筛选 — 这是组出 **+20 % HP/ATK/DEF 纯阵营队**最快的办法（见团队指南）。
- **星星宝箱**（0/15）：累积已通关卡的星星并开箱。

## 2. 挂机收益 — 真正的价值

- 自动累积，离线也算。第 308 关的速率示例：

| 资源 | 速率 |
|------|------|
| 铁 | 165.6K/小时 |
| 面包 | 165.6K/小时 |
| 黄金 | 111.6K/小时 |

- **存储只能装 14.57 小时。** 超出的部分全部丢失。
- → **每天至少领两次**，最好早晚各一次。一天只领一次，等于丢掉约 40 % 的日产量。
- *速率是否随推图进度提升，截图中没有说明 — 关卡大幅推进后可在游戏内对比。*

## 3. 推荐步骤

| 步骤 | 操作 |
|------|------|
| 1 | 在 14.57 小时存满之前领取挂机奖励 |
| 2 | 检查阵容 — 尽量用同一阵营的五名英雄 |
| 3 | 开始挑战；失败后不要盲目重打，先提升英雄等级、星级或装备 |
| 4 | 攒到 15 星就开星星宝箱 |

## 4. 联动

- **排行榜：** 「Cleared Stages Count」是独立的榜单（见个人资料手册）。
- 挂机得到的资源是研究和建造的长期收入 — 因而也间接转化为对应 **Arms Race** 阶段的积分。

- [ ] 阵容为纯阵营（+20 %）
- [ ] 进攻前比对过敌方 CP
- [ ] 星星宝箱已开
