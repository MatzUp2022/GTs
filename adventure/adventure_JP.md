# Adventure — ステージ進行と放置収入 (Last Light)

## 1. 基本ルール

- ひと続きの**ステージマップ**。**Challenge** で、編成した5体のヒーローで現在のステージに挑む。
- 戦闘前に画面上部へ双方の **CP** が表示される（ステージ308の例: 自分 8.74M 対 4.49M）— そのステージを越えられるかの最良の目安。
- 編成画面のアイコンで **ALL / Guardian / Ranger / Berserker** に絞り込める — **+20 % HP/ATK/DEF の単一陣営編成**を組む最短の手順（チームガイド参照）。
- **星の宝箱**（0/15）: クリア済みステージの星を集めて宝箱を開ける。

## 2. 放置収入 — 本当の価値

- オフラインでも自動的に貯まる。ステージ308での目安:

| 資源 | 速度 |
|------|------|
| 鉄 | 165.6K/時 |
| パン | 165.6K/時 |
| ゴールド | 111.6K/時 |

- **貯蔵できるのは14.57時間分だけ。** それを超えた分は失われる。
- → **1日に最低2回は回収する**。できれば朝と夜。1日1回だと日産のおよそ40 %を捨てることになる。
- *ステージ進行につれて速度が上がるかはスクリーンショットに記載がない — ステージが大きく進んだ後にゲーム内で比較すること。*

## 3. 推奨手順

| 手順 | 内容 |
|------|------|
| 1 | 14.57時間分が埋まる前に放置報酬を回収 |
| 2 | 編成を確認 — 可能なら同一陣営の5体 |
| 3 | チャレンジを開始。負けたらそのまま再挑戦せず、まずヒーローのレベル・星・装備を上げる |
| 4 | 星が15個たまったら宝箱を開ける |

## 4. 連動

- **ランキング:** 「Cleared Stages Count」は独立したランキング（プロフィールの手引き参照）。
- 放置で得た資源は研究と建設の恒常的な収入 — つまり対応する **Arms Race** フェーズのポイントにも間接的につながる。
