# Profiel, instellingen & ranglijsten — Gids (Last Light)

## 1. Home (profielkaart)

- Toont avatar, naam met alliantietag (bijv. `[GTs] MatzeUp`), **ID**, baseniveau, **CP**, alliantie en **server** (bijv. #149).
- De klantenservice heeft bij elk verzoek het **ID** nodig — schrijf het op.
- Knoppen: **Leaderboard · Style · Log**.

## 2. Ranglijsten

| Alliantie | Persoonlijk |
|-----------|-------------|
| Alliance Leaderboard | Personal CP · Commander Base · Commander Kill |
| Alliance Kill Leaderboard | Cleared Stages Count · Total Hero CP · Strongest Hero CP |
| | Guardian- / Ranger- / Berserker-trialranglijsten |

- **Aanwijzingen uit het spel:** de lijsten worden **niet in realtime bijgewerkt** en kunnen achterlopen. Bij *Strongest Hero CP* telt alleen **je allersterkste held**, niet de som.
- De drie trialranglijsten laten zien waar elke factie-opstelling staat — handig om je zwakste van de drie te herkennen.

## 3. Instellingen

| Punt | Waarom het uitmaakt |
|------|---------------------|
| **Bind Account** | Zonder koppeling is het account weg als je het apparaat kwijtraakt — **doe dit als eerste** |
| **Exchange Code** | Cadeau- en vouchercodes inwisselen |
| **Switch Account / Select Server** | Account en server wisselen |
| **Push Notifications** | Herinneringen voor eventtijden en een volle AFK-opslag |
| Taal · blokkeerlijst · banner | Weergave en chatmoderatie |
| **Framerate 30 / 60 fps** | 60 fps kost batterij en geeft warmte — zet 30 fps aan bij lange SvS-sessies |

*Gedocumenteerde clientversie: 1.0.46.*
