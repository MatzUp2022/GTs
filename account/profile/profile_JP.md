# プロフィール・設定・ランキング — ガイド (Last Light)

## 1. Home（プロフィールカード）

- アバター、同盟タグ付きの名前（例: `[GTs] MatzeUp`）、**ID**、拠点レベル、**CP**、同盟、**サーバー**（例: #149）が表示される。
- カスタマーサービスは問い合わせのたびに **ID** を求める — 控えておくこと。
- ボタン: **Leaderboard · Style · Log**。

## 2. ランキング

| 同盟 | 個人 |
|------|------|
| Alliance Leaderboard | Personal CP · Commander Base · Commander Kill |
| Alliance Kill Leaderboard | Cleared Stages Count · Total Hero CP · Strongest Hero CP |
| | Guardian / Ranger / Berserker のトライアルランキング |

- **ゲーム内の注記:** ランキングは**リアルタイム更新ではなく**、遅れることがある。*Strongest Hero CP* は合計ではなく、**最も強いヒーロー1体のみ**が対象。
- 3つのトライアルランキングは各陣営編成の位置を示す — 3つのうちどれが最も弱いかを見つけるのに便利。

## 3. 設定

| 項目 | 重要な理由 |
|------|------------|
| **Bind Account** | 連携していないと端末を失った時点でアカウントも消える — **まずこれを済ませる** |
| **Exchange Code** | ギフトコード・引換コードの入力 |
| **Switch Account / Select Server** | アカウントとサーバーの切り替え |
| **Push Notifications** | イベント時刻と AFK ストレージ満杯の通知 |
| 言語 · ブロックリスト · バナー | 表示とチャットのモデレーション |
| **フレームレート 30 / 60 fps** | 60 fps はバッテリーを食い発熱する — 長い SvS セッションでは 30 fps に |

*記録したクライアントバージョン: 1.0.46。*
