# Profil, réglages & classements — Guide (Last Light)

## 1. Home (carte de profil)

- Affiche l'avatar, le nom avec le tag d'alliance (p. ex. `[GTs] MatzeUp`), l'**ID**, le niveau de base, le **CP**, l'alliance et le **serveur** (p. ex. #149).
- Le service client réclame l'**ID** à chaque demande — à noter.
- Boutons : **Leaderboard · Style · Log**.

## 2. Classements (Leaderboard)

| Alliance | Personnel |
|----------|-----------|
| Alliance Leaderboard | Personal CP · Commander Base · Commander Kill |
| Alliance Kill Leaderboard | Cleared Stages Count · Total Hero CP · Strongest Hero CP |
| | Classements des épreuves Guardian / Ranger / Berserker |

- **Notes du jeu :** les classements **ne se mettent pas à jour en temps réel** et peuvent être retardés. Pour *Strongest Hero CP*, seul **le héros le plus fort** compte, pas la somme.
- Les trois classements d'épreuve montrent où en est chaque composition de faction — pratique pour repérer la plus faible des trois.

## 3. Réglages (Settings)

| Élément | Pourquoi c'est important |
|---------|--------------------------|
| **Bind Account** | Sans liaison, le compte est perdu avec l'appareil — **à faire en premier** |
| **Exchange Code** | Échanger les codes cadeaux |
| **Switch Account / Select Server** | Changer de compte et de serveur |
| **Push Notifications** | Rappels pour les horaires d'événement et le stock AFK plein |
| Langue · Block List · bannière | Affichage et modération du chat |
| **Frame Rate 30 / 60 fps** | 60 fps vide la batterie et chauffe — passer à 30 fps pour les longues sessions SvS |

*Version du client documentée : 1.0.46.*
