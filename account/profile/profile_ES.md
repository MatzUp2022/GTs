# Perfil, ajustes y clasificaciones — Guía (Last Light)

## 1. Home (tarjeta de perfil)

- Muestra avatar, nombre con la etiqueta de alianza (p. ej. `[GTs] MatzeUp`), **ID**, nivel de base, **CP**, alianza y **servidor** (p. ej. #149).
- Atención al cliente pide la **ID** en cada consulta — anótala.
- Botones: **Leaderboard · Style · Log**.

## 2. Clasificaciones (Leaderboard)

| Alianza | Personal |
|---------|----------|
| Alliance Leaderboard | Personal CP · Commander Base · Commander Kill |
| Alliance Kill Leaderboard | Cleared Stages Count · Total Hero CP · Strongest Hero CP |
| | Clasificaciones de prueba Guardian / Ranger / Berserker |

- **Notas del juego:** las tablas **no se actualizan en tiempo real** y pueden ir con retraso. En *Strongest Hero CP* solo cuenta **el héroe más fuerte**, no la suma.
- Las tres tablas de prueba muestran dónde está cada formación de facción — útil para detectar la más floja de las tres.

## 3. Ajustes (Settings)

| Elemento | Por qué importa |
|----------|-----------------|
| **Bind Account** | Sin vinculación, la cuenta se pierde con el dispositivo — **hazlo primero** |
| **Exchange Code** | Canjear códigos de regalo |
| **Switch Account / Select Server** | Cambiar de cuenta y de servidor |
| **Push Notifications** | Avisos de horarios de evento y almacén AFK lleno |
| Idioma · Block List · banner | Presentación y moderación del chat |
| **Frame Rate 30 / 60 fps** | 60 fps gasta batería y genera calor — poner 30 fps en sesiones largas de SvS |

*Versión del cliente documentada: 1.0.46.*
