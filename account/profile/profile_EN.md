# Profile, Settings & Leaderboards — Guide (Last Light)

## 1. Home (profile card)

- Shows avatar, name with alliance tag (e.g. `[GTs] MatzeUp`), **ID**, base level, **CP**, alliance and **server** (e.g. #149).
- Customer service needs the **ID** for every request — note it down.
- Buttons: **Leaderboard · Style · Log**.

## 2. Leaderboards

| Alliance | Personal |
|----------|----------|
| Alliance Leaderboard | Personal CP · Commander Base · Commander Kill |
| Alliance Kill Leaderboard | Cleared Stages Count · Total Hero CP · Strongest Hero CP |
| | Guardian / Ranger / Berserker trial leaderboards |

- **Notes from the game:** the boards do **not update in real time** and may lag. For *Strongest Hero CP* only **your single strongest hero** counts, not the sum.
- The three trial boards show where each faction line-up stands — handy for spotting your weakest of the three.

## 3. Settings

| Item | Why it matters |
|------|----------------|
| **Bind Account** | Without binding the account is gone if you lose the device — **do this first** |
| **Exchange Code** | Redeem gift and voucher codes |
| **Switch Account / Select Server** | Change account and server |
| **Push Notifications** | Reminders for event times and a full AFK storage |
| Language · Block List · banner | Presentation and chat moderation |
| **Frame rate 30 / 60 fps** | 60 fps drains battery and generates heat — switch to 30 fps for long SvS sessions |

*Documented client version: 1.0.46.*
