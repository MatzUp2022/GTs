# Профиль, настройки и таблицы лидеров — Руководство (Last Light)

## 1. Home (карточка профиля)

- Показывает аватар, имя с тегом альянса (например, `[GTs] MatzeUp`), **ID**, уровень базы, **CP**, альянс и **сервер** (например, #149).
- Службе поддержки **ID** нужен при каждом обращении — выпишите его.
- Кнопки: **Leaderboard · Style · Log**.

## 2. Таблицы лидеров

| Альянс | Личные |
|--------|--------|
| Alliance Leaderboard | Personal CP · Commander Base · Commander Kill |
| Alliance Kill Leaderboard | Cleared Stages Count · Total Hero CP · Strongest Hero CP |
| | Таблицы испытаний Guardian / Ranger / Berserker |

- **Примечания из игры:** таблицы **не обновляются в реальном времени** и могут отставать. В *Strongest Hero CP* учитывается только **один ваш сильнейший герой**, а не сумма.
- Три таблицы испытаний показывают, где находится каждый фракционный состав — удобно, чтобы найти самый слабый из трёх.

## 3. Настройки

| Пункт | Почему это важно |
|-------|------------------|
| **Bind Account** | Без привязки аккаунт теряется вместе с устройством — **сделайте это первым делом** |
| **Exchange Code** | Активация подарочных и промо-кодов |
| **Switch Account / Select Server** | Смена аккаунта и сервера |
| **Push Notifications** | Напоминания о времени событий и о заполненном AFK-хранилище |
| Язык · чёрный список · баннер | Оформление и модерация чата |
| **Частота кадров 30 / 60 fps** | 60 fps сажает батарею и греет устройство — на долгих сессиях SvS переключитесь на 30 fps |

*Задокументированная версия клиента: 1.0.46.*
