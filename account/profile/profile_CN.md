# 个人资料、设置与排行榜 — 指南 (Last Light)

## 1. Home（资料卡）

- 显示头像、带联盟标签的名字（例如 `[GTs] MatzeUp`）、**ID**、基地等级、**CP**、联盟和**服务器**（例如 #149）。
- 客服每次处理问题都需要 **ID** — 记下来。
- 按钮：**Leaderboard · Style · Log**。

## 2. 排行榜

| 联盟 | 个人 |
|------|------|
| Alliance Leaderboard | Personal CP · Commander Base · Commander Kill |
| Alliance Kill Leaderboard | Cleared Stages Count · Total Hero CP · Strongest Hero CP |
| | Guardian / Ranger / Berserker 试炼排行榜 |

- **游戏内提示：** 排行榜**不是实时更新**，可能有延迟。*Strongest Hero CP* 只计算**你最强的那一个英雄**，不是总和。
- 三个试炼榜显示各阵营阵容的位置 — 便于找出三者中最弱的一个。

## 3. 设置

| 项目 | 为什么重要 |
|------|------------|
| **Bind Account** | 不绑定的话，设备一丢账号就没了 — **先做这一项** |
| **Exchange Code** | 兑换礼包码和兑换码 |
| **Switch Account / Select Server** | 切换账号与服务器 |
| **Push Notifications** | 活动时间与 AFK 存储已满的提醒 |
| 语言 · 屏蔽列表 · 横幅 | 显示与聊天管理 |
| **帧率 30 / 60 fps** | 60 fps 耗电且发热 — 长时间 SvS 时切到 30 fps |

*记录的客户端版本：1.0.46。*
