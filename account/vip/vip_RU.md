# Система VIP — Руководство (Last Light)

## 1. Основные правила

- Уровни VIP растут за счёт **VIP EXP**: ежедневная **серия входов** (например, 200 EXP в день при серии в 45 дней), а также покупной EXP («+») и наборы с месячной картой / VIP.
- Привилегии **накапливаются** — каждый уровень сохраняет все прежние бонусы и часть из них улучшает.
- Забирать ежедневно: **ежедневный сундук** (полоса VIP) и **VIP daily free pack** (растёт с уровнем, например VIP11: 1 пазл + по 11 сундуков каждого ресурса) — сгорает через 24 ч.
- На каждом уровне есть разовый **эксклюзивный набор** (лимит покупки 1); кроме того, работает **VIP-магазин**.

## 3. Ключевые вехи

- **VIP 4:** автоотправка в таверне — задания идут без ручного назначения.
- **VIP 8:** второй быстрый бой в Faction Trial + марш +10 %.
- **VIP 10:** первые по-настоящему боевые бонусы (HP/ATK/DEF героев +2,5 %, лечение +10 %).
- **VIP 12:** суперрежим Outpost Tavern + характеристики героев +5 %.

## 4. Чек-лист (ежедневно)

- [ ] Вход выполнен (серия входов = VIP EXP)
- [ ] Ежедневный сундук на полосе VIP открыт
- [ ] VIP daily free pack забран (сгорает!)
- [ ] VIP-магазин проверен на предложения
