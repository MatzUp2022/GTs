# VIP-systeem — Gids (Last Light)

## 1. Basisregels

- VIP-niveaus stijgen via **VIP EXP**: dagelijkse **login-streak** (bijv. 200 EXP/dag bij een streak van 45 dagen), plus koopbare EXP ("+") en maandkaart-/VIP-pakketten.
- Privileges zijn **cumulatief** — elk niveau behoudt alle eerdere voordelen en verbetert sommige ervan.
- Dagelijks ophalen: de **dagkist** (VIP-balk) en het **VIP daily free pack** (groeit met het niveau, bijv. VIP11: 1 puzzel + 11 van elke grondstofkist) — vervalt na 24 u.
- Elk niveau heeft een eenmalig **exclusief pakket** (kooplimiet 1); daarnaast is er een **VIP-winkel**.

## 2. Verloop van de privileges (wat er per niveau bij komt)

| VIP | Belangrijkste toevoegingen |
|-----|----------------------------|
| 1 | Voedsel +5 % · grondstoffen in bulk innen (vanaf base 20) · avatarweergave · Faction Trial snelgevecht |
| 2 | IJzer +5 % · goud +5 % |
| 3 | Bouwen +10 % |
| 4 | Productie +10 % · mars +5 % · **automatisch uitsturen van tavernmissies** |
| 5 | Bouwen +20 % · uitrusting maken +25 % |
| 6 | Productie +15 % · capaciteit oefenterrein +5 % |
| 7 | Bouwen +30 % · tech +5 % |
| 8 | Productie +20 % · mars +10 % · **2e Faction Trial-snelgevecht** |
| 9 | Bouwen +40 % · tech +10 % |
| 10 | Productie +25 % · genezen +10 % · **held HP/ATK/DEF +2,5 %** |
| 11 | Bouwen +50 % · tech +15 % |
| 12 | Mars +15 % · heldenwaarden +5 % · **Outpost Tavern supermodus** |
| 13 | Crafting +50 % · tech +20 % |

*Productie = productiesnelheid van voedsel/ijzer/goud.*

## 3. Belangrijkste mijlpalen

- **VIP 4:** taverne-auto-dispatch — tavernmissies lopen zonder handmatige toewijzing.
- **VIP 8:** tweede Faction Trial-snelgevecht + mars +10 %.
- **VIP 10:** de eerste echte gevechtsvoordelen (held HP/ATK/DEF +2,5 %, genezen +10 %).
- **VIP 12:** Outpost Tavern supermodus + heldenwaarden +5 %.

## 4. Checklist (dagelijks)

- [ ] Ingelogd (login-streak = VIP EXP)
- [ ] Dagkist op de VIP-balk geopend
- [ ] VIP daily free pack opgehaald (vervalt!)
- [ ] VIP-winkel op aanbiedingen gecontroleerd
