# VIP システム — ガイド (Last Light)

## 1. 基本ルール

- VIPレベルは **VIP EXP** で上がる: 毎日の**ログイン継続**（例: 45日継続で1日200 EXP）に加え、購入できるEXP（「+」）や月間カード / VIPパック。
- 特典は**累積する** — 上の階層は下の特典をすべて保持し、一部を強化する。
- 毎日受け取るもの: **デイリー宝箱**（VIPバー）と **VIP daily free pack**（レベルとともに増える。例: VIP11 は パズル1 + 各資源宝箱11）— 24時間で失効。
- 各レベルに一度きりの**専用パック**（購入上限1）があり、**VIPショップ**も利用できる。

## 2. 特典の推移（レベルごとの追加分）

| VIP | 主な追加 |
|-----|----------|
| 1 | 食料 +5 % · 資源の一括回収（拠点20から）· アバター閲覧 · Faction Trial のクイックバトル |
| 2 | 鉄 +5 % · ゴールド +5 % |
| 3 | 建設 +10 % |
| 4 | 生産 +10 % · 行軍 +5 % · **酒場ミッションの自動派遣** |
| 5 | 建設 +20 % · 装備製作 +25 % |
| 6 | 生産 +15 % · 練兵場の収容数 +5 % |
| 7 | 建設 +30 % · テック +5 % |
| 8 | 生産 +20 % · 行軍 +10 % · **Faction Trial クイックバトル 2回目** |
| 9 | 建設 +40 % · テック +10 % |
| 10 | 生産 +25 % · 治療 +10 % · **ヒーロー HP/ATK/DEF +2.5 %** |
| 11 | 建設 +50 % · テック +15 % |
| 12 | 行軍 +15 % · ヒーロー能力 +5 % · **Outpost Tavern スーパーモード** |
| 13 | 製作 +50 % · テック +20 % |

*生産 = 食料/鉄/ゴールドの生産速度。*

## 3. 重要な節目

- **VIP 4:** 酒場の自動派遣 — 手動で割り当てなくても酒場ミッションが回る。
- **VIP 8:** Faction Trial のクイックバトル2回目 + 行軍 +10 %。
- **VIP 10:** 初めての本格的な戦闘特典（ヒーロー HP/ATK/DEF +2.5 %、治療 +10 %）。
- **VIP 12:** Outpost Tavern スーパーモード + ヒーロー能力 +5 %。

- [ ] ログインした（ログイン継続 = VIP EXP）
- [ ] VIPバーのデイリー宝箱を開けた
- [ ] VIP daily free pack を受け取った（失効する）
- [ ] VIPショップの品揃えを確認した
