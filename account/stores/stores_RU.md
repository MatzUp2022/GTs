# Stores — Diamond Store и другие (Last Light)

## 1. Обзор

- Панель магазинов в игре: **Diamond Store · VIP Shop · Alliance Store · Honor Store** (…).
- **Goods Refresh Ticket** (100 алмазов) обновляет ассортимент.

## 2. Diamond Store — прайс-лист

| Товар | Алмазы |
|-------|--------|
| Hero Recruit Ticket | 400 |
| Survivor Recruit Ticket | 400 |
| 50K железа | 50 |
| 50K хлеба | 50 |
| 18K золота | 50 |
| Goods Refresh Ticket | 100 |
| Premium Relocation | 1 500 |
| Alliance Relocation | 500 |

## 3. Оценка выгоды

- **Ресурсы дёшевы** (по 50 алмазов) — годятся как заполнение перед фазами Arms Race.
- **Переезды:** чтобы перебраться к своему альянсу, достаточно **Alliance Relocation (500)** — втрое дешевле свободно размещаемого Premium Relocation (1 500). Важно для **Region Duel** (суббота: переезд во вражеский регион).
- Перед покупкой сравните рекрут-билеты (по 400) с предложениями в событиях.

## 4. Чек-лист

- [ ] Бюджет алмазов отложен на переезды в SvS (Alliance Relocation)
- [ ] Покупка ресурсов назначена на подходящую фазу Arms Race
- [ ] VIP-, Alliance- и Honor-магазины регулярно проверяются на предложения
