# Stores — Diamond Store ほか (Last Light)

## 1. 概要

- ゲーム内のショップバー: **Diamond Store · VIP Shop · Alliance Store · Honor Store**（…）。
- **Goods Refresh Ticket**（ダイヤ100）で品揃えを更新できる。

## 2. Diamond Store — 価格表

| 品目 | ダイヤ |
|------|--------|
| Hero Recruit Ticket | 400 |
| Survivor Recruit Ticket | 400 |
| 鉄 50K | 50 |
| パン 50K | 50 |
| ゴールド 18K | 50 |
| Goods Refresh Ticket | 100 |
| Premium Relocation | 1,500 |
| Alliance Relocation | 500 |

## 3. 価値の判断

- **資源は安い**（各ダイヤ50）— Arms Race フェーズ前の埋め合わせに使える。
- **移転:** 自分の同盟のそばへ移るだけなら **Alliance Relocation（500）** で足りる — 自由に配置できる Premium Relocation（1,500）の3分の1。**Region Duel**（土曜: 敵リージョンへの移転）で重要。
- リクルートチケット（各400）は、ここで買う前にイベントの提供品と比較すること。
