# Help & FAQ — ガイド (Last Light)

*ゲーム内ではプロフィール → **Help**（タブ: Home · Settings · Help）。そこの **Feedback** ボタンからカスタマーサービスに届く。*

## 1. ゲームと技術

| 症状 | 対処 |
|------|------|
| 端末を変える | ゲームをインストールし、ログイン画面でアカウントとパスワードでログイン |
| アカウントの乗っ取り / パスワード変更 | **ただちにカスタマーサービスへ連絡** |
| ログインのタイムアウト | 再接続するかゲームを再起動 |
| 更新中に固まる | アプリを終了するかネットワークを切り替えて入り直す。直らなければカスタマーサービス |
| ゲームデータが「消えた」 | **サーバーが合っているか確認** — データはサーバー間で共有されない。違う場合は game ID とアカウント名を添えてサポートへ |
| 頻繁に切断される | ネットワークを確認。直らなければカスタマーサービス |
| クラッシュ | アプリを閉じて開き直す。端末を再起動。直らなければカスタマーサービス |
| チーターを見つけた | 速やかに通報（カスタマーサービス） |

## 2. ソーシャルと同盟

- **チャットの広告・詐欺:** 相手の account ID を添えてカスタマーサービスへ通報。
- **同盟への加入:** Alliance Center を建てる → おすすめの同盟を選ぶか ID で検索 → 申請を送る。または自分で設立する。
- **同盟の移籍:** 一部のイベント中は移籍で**報酬の受け取り資格を失う**ことがある — イベントの最中に移籍しないこと。
- **Alliance Tech:** ゴールドやダイヤの寄付でテックのEXPバーが埋まり、満タンになると同盟がそのテックを研究できる。
- **Alliance Help:** 仲間が建設・研究・兵士の治療を加速してくれる — 助けを送り、助けを求める。

## 3. 課金（Recharge）

- **VIP:** VIPステータスまたは月間カードのパックから。VIPレベルが高いほど特典が多い。
- **初回課金:** 超レアなS+ヒーロー、10連リクルートチケットなどが開放される。
- **支払ったのに届かない:** ゲームを再起動。それでも届かなければ → カスタマーサービス。
- **金額が違う:** 現地通貨への換算によるもの。為替レートは変動する。

## 4. 同盟向けチートシート

- [ ] アカウントにパスワードを設定済み（端末変更時に重要）
- [ ] サーバー番号を控えた（例: #149）
- [ ] 進行中のイベント中に同盟を移籍していない
- [ ] Alliance Help を毎日利用（送る・求める）
- [ ] 不具合は Feedback ボタンから報告
