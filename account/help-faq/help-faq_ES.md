# Help & FAQ — Guía (Last Light)

*En el juego vía perfil → **Help** (pestañas: Home · Settings · Help); el botón **Feedback** contacta con atención al cliente.*

## 1. Juego y técnica

| Problema | Solución |
|----------|----------|
| Cambio de dispositivo | Instalar el juego e iniciar sesión con cuenta + contraseña en la pantalla de acceso |
| Cuenta robada / contraseña cambiada | **Contactar de inmediato con atención al cliente** |
| Timeout al iniciar sesión | Reconectar o reiniciar el juego |
| Juego atascado actualizando | Cerrar la app o cambiar de red, volver a entrar; si no, atención al cliente |
| Datos de juego «perdidos» | **Comprobar el servidor correcto** — los datos no se comparten entre servidores; si no, contactar con soporte con ID de juego + nombre de cuenta |
| Desconexiones frecuentes | Revisar la red; si no, atención al cliente |
| Cierres inesperados | Cerrar y reabrir la app; reiniciar el dispositivo; si no, atención al cliente |
| Tramposo detectado | Denunciarlo cuanto antes (atención al cliente) |

## 2. Social y alianza

- **Publicidad/fraude en el chat:** denunciar a atención al cliente con la ID de cuenta del jugador.
- **Unirse a una alianza:** construir el Alliance Center → elegir una alianza recomendada o buscar por ID → enviar solicitud; o crear una propia.
- **Cambiar de alianza:** durante ciertos eventos, cambiar puede **costar el derecho a recompensas** — ¡no cambiar en pleno evento!
- **Alliance Tech:** las contribuciones de oro o diamantes llenan la barra de EXP; al llenarse, la alianza puede investigar la tecnología.
- **Alliance Help:** los aliados aceleran construcciones, investigación y curación de soldados — dar y pedir ayuda.

## 3. Compras (recarga)

- **VIP:** mediante el estado VIP o los packs de tarjeta mensual; a mayor nivel VIP, más ventajas.
- **Primera recarga:** desbloquea héroes S+ ultra raros, tickets de reclutamiento ×10 y otras ofertas.
- **Pagado pero sin recibir nada:** reiniciar el juego; si sigue sin llegar → atención al cliente.
- **Importe distinto:** conversión a la moneda local; el tipo de cambio puede fluctuar.
