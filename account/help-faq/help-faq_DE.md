# Help & FAQ — Guide (Last Light)

*Im Spiel erreichbar über Profil → **Help** (Tabs: Home · Settings · Help); dort auch der **Feedback**-Button für den Kundendienst.*

## 1. Spiel & Technik

| Problem | Lösung |
|---------|--------|
| Gerätewechsel | Spiel installieren, im Login mit Account + Passwort anmelden |
| Account gestohlen / Passwort geändert | **Sofort den Kundendienst kontaktieren** |
| Login-Timeout | Neu verbinden oder Spiel neu starten |
| Spiel hängt im Update | App beenden oder Netzwerk wechseln, neu starten; sonst Kundendienst |
| Spieldaten „weg" | **Richtigen Server prüfen** — Daten werden nicht zwischen Servern geteilt; sonst Kundendienst mit Game-ID + Accountname |
| Häufige Disconnects | Netzwerk prüfen; sonst Kundendienst |
| Abstürze | App beenden und neu öffnen; Gerät neu starten; sonst Kundendienst |
| Cheater entdeckt | Umgehend melden (Kundendienst) |

## 2. Soziales & Allianz

- **Werbung/Betrug im Chat:** Beim Kundendienst mit der Account-ID des Spielers melden.
- **Allianz beitreten:** Alliance Center bauen → empfohlene Allianz wählen oder per ID suchen → Bewerbung senden; alternativ eigene Allianz gründen.
- **Allianzwechsel:** Während bestimmter Events kann ein Wechsel die **Belohnungs-Berechtigung kosten** — nicht mitten im Event wechseln!
- **Alliance Tech:** Beiträge mit Gold oder Diamanten füllen die Tech-EXP-Leiste; ist sie voll, kann die Allianz die Technologie erforschen.
- **Alliance Help:** Verbündete beschleunigen Bauten, Forschung und das Heilen von Soldaten — Hilfe geben und anfordern.

## 3. Käufe (Recharge)

- **VIP:** über VIP-Status- oder Monatskarten-Pakete; höheres VIP-Level = mehr Vorteile.
- **Erster Kauf:** schaltet u. a. Ultra-Rare-S+-Helden und 10er-Rekrutierungs-Tickets frei.
- **Bezahlt, aber nichts erhalten:** Spiel neu starten; bleibt es aus → Kundendienst.
- **Abweichender Betrag:** Umrechnung in die Landeswährung, Wechselkurs kann schwanken.

## 4. Merkzettel für die Allianz

- [ ] Account mit Passwort gesichert (wichtig für Gerätewechsel)
- [ ] Servernummer notiert (z. B. #149)
- [ ] Keine Allianzwechsel während laufender Events
- [ ] Alliance Help täglich genutzt (geben + anfordern)
- [ ] Probleme über den Feedback-Button melden
