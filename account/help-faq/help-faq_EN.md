# Help & FAQ — Guide (Last Light)

*In game via profile → **Help** (tabs: Home · Settings · Help); the **Feedback** button there reaches customer service.*

## 1. Game & Technical

| Problem | Solution |
|---------|----------|
| Changing device | Install the game, log in with account + password on the login screen |
| Account stolen / password changed | **Contact customer service immediately** |
| Login timeout | Reconnect or restart the game |
| Game stuck updating | Close the app or switch networks, re-enter; otherwise customer service |
| Game data "gone" | **Check the correct server** — data is not shared between servers; otherwise contact support with game ID + account name |
| Frequent disconnects | Check your network; otherwise customer service |
| Crashes | Close and reopen the app; restart the device; otherwise customer service |
| Cheater found | Report them promptly (customer service) |

## 2. Social & Alliance

- **Ads/fraud in chat:** report to customer service with the player's account ID.
- **Joining an alliance:** build the Alliance Center → pick a recommended alliance or search by ID → send an application; or create your own.
- **Switching alliances:** during certain events a switch can **cost your reward eligibility** — don't switch mid-event!
- **Alliance Tech:** contributions of gold or diamonds fill the tech EXP bar; once full, the alliance can research the tech.
- **Alliance Help:** allies speed up construction, research and healing of soldiers — give and request help.

## 3. Purchases (Recharge)

- **VIP:** via VIP status or monthly card packs; higher VIP level = more perks.
- **First recharge:** unlocks ultra-rare S+ heroes, 10-pull recruit tickets and other deals.
- **Paid but nothing received:** restart the game; if it stays missing → customer service.
- **Amount differs:** conversion to your local currency, exchange rates can fluctuate.

## 4. Alliance Cheat Sheet

- [ ] Account secured with a password (important for device changes)
- [ ] Server number noted (e.g. #149)
- [ ] No alliance switches during running events
- [ ] Alliance Help used daily (give + request)
- [ ] Problems reported via the Feedback button
