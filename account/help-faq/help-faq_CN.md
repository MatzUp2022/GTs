# Help & FAQ — 指南 (Last Light)

*游戏内：头像 → **Help**（标签页：Home · Settings · Help）；其中的 **Feedback** 按钮可联系客服。*

## 1. 游戏与技术

| 问题 | 处理 |
|------|------|
| 更换设备 | 安装游戏，在登录界面用账号 + 密码登录 |
| 账号被盗 / 密码被改 | **立即联系客服** |
| 登录超时 | 重新连接或重启游戏 |
| 更新卡住 | 关闭应用或切换网络后重进；不行则联系客服 |
| 游戏数据「不见了」 | **先确认服务器是否正确** — 数据不跨服共享；否则带上 game ID 和账号名联系客服 |
| 频繁掉线 | 检查网络；不行则联系客服 |
| 闪退 | 关闭并重开应用；重启设备；不行则联系客服 |
| 发现作弊者 | 及时举报（客服） |

## 2. 社交与联盟

- **聊天中的广告/诈骗：** 附上对方的 account ID 向客服举报。
- **加入联盟：** 建造 Alliance Center → 选择推荐联盟或按 ID 搜索 → 发送申请；也可以自己创建。
- **更换联盟：** 某些活动期间更换会**失去奖励资格** — 活动进行中不要换盟！
- **Alliance Tech：** 捐献黄金或钻石可填充科技 EXP 条；满了之后联盟即可研究该科技。
- **Alliance Help：** 盟友可以加速建造、研究和士兵治疗 — 要给别人帮助，也要主动求助。

## 3. 充值（Recharge）

- **VIP：** 通过 VIP 状态或月卡礼包；VIP 等级越高特权越多。
- **首充：** 解锁超稀有 S+ 英雄、10 连招募券及其他优惠。
- **付了钱但没到账：** 重启游戏；仍然没有 → 联系客服。
- **金额对不上：** 换算成本地货币所致，汇率会波动。
