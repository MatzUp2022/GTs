# Help & FAQ — Руководство (Last Light)

*В игре: профиль → **Help** (вкладки: Home · Settings · Help); кнопка **Feedback** там ведёт в службу поддержки.*

## 1. Игра и техника

| Проблема | Решение |
|----------|---------|
| Смена устройства | Установить игру и войти на экране входа по аккаунту и паролю |
| Аккаунт угнали / пароль изменён | **Немедленно обратиться в службу поддержки** |
| Тайм-аут входа | Переподключиться или перезапустить игру |
| Игра зависла на обновлении | Закрыть приложение или сменить сеть, зайти снова; иначе — поддержка |
| Игровые данные «пропали» | **Проверьте, тот ли сервер** — данные между серверами не общие; иначе обратитесь в поддержку с game ID и именем аккаунта |
| Частые обрывы связи | Проверить сеть; иначе — поддержка |
| Вылеты | Закрыть и снова открыть приложение; перезагрузить устройство; иначе — поддержка |
| Найден читер | Сразу пожаловаться (служба поддержки) |

## 2. Общение и альянс

- **Реклама и мошенничество в чате:** сообщить в поддержку, указав account ID игрока.
- **Вступление в альянс:** построить Alliance Center → выбрать рекомендованный альянс или найти по ID → отправить заявку; либо создать свой.
- **Смена альянса:** во время некоторых событий смена может **лишить права на награды** — не меняйте альянс посреди события!
- **Alliance Tech:** пожертвования золотом или алмазами заполняют полосу EXP технологии; когда она полна, альянс может её исследовать.
- **Alliance Help:** соратники ускоряют строительство, исследования и лечение солдат — помогайте и просите помощь.

## 3. Покупки (Recharge)

- **VIP:** через статус VIP или наборы с месячной картой; чем выше уровень VIP, тем больше привилегий.
- **Первое пополнение:** открывает сверхредких героев S+, билеты на 10 призывов и другие предложения.
- **Оплатили, но ничего не пришло:** перезапустить игру; если не появилось → служба поддержки.
- **Сумма отличается:** пересчёт в вашу валюту, курсы могут колебаться.

## 4. Шпаргалка для альянса

- [ ] Аккаунт защищён паролем (важно при смене устройства)
- [ ] Номер сервера записан (например, #149)
- [ ] Никаких смен альянса во время идущих событий
- [ ] Alliance Help используется ежедневно (давать и просить)
- [ ] О проблемах сообщено через кнопку Feedback
